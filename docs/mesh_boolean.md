# 网格级正则布尔（GAP-CAD-003）—— 实现与实测台账

> 仓 TensorCAD · 模块 `tensorcad/mesh_boolean.py` · 测试 `tests/test_mesh_boolean.py`
> 数字全部由 `artifacts/mesh_boolean_v1/results.json` 插值，禁止手抄；复现见文末。

## 1 案例介绍（为什么需要这一条）

船舶总体性能的所有学科都要在几何上做**布尔**：甲板开口/舱壁穿舱、船体与附体的并、
压载舱的分割、结构开孔。TensorCAD 之前只有 `tensorcad/csg.py` —— 它是**隐式场**上的
并/交/差：操作数是 `GeometryField`，结果是体素场。对"雕一个船体包络"这是对的工具，对
"在甲板上开一个舱口"就是错的工具：答案是**带切口的曲面**，而场答案必须重新网格化，切口
边界只要不落在网格线上就丢失了。

本单补的是另一种表示：**闭合三角网格进、闭合三角网格出**。

## 2 怎么做的（算法与关键设置）

先走了经典 BSP 路线（Naylor/Thibault，`csg.js` 的表述），**实测失败**：`csg.js` 对**共面
多边形**按"朝向"分类，这在两面完全重合或完全不相交时正确，在两面**部分重叠**时错误 ——
而"切口与面齐平"正是部分重叠的典型。实测：立方体减去齐平贯穿的圆柱，BSP 管线返回
**3184 面、300 条边界边**的
非闭合面（该次运行在 `_validate` 处被拒绝），因此该路线**不上线**，只留作否定性记录。

改用**曲面分类法**（surface classification）：

1. 取另一操作数 B 的**全部支撑平面**（三角形所在平面，按模型相对容差去重）；
2. 用这些平面把 A 的每个三角形**两边都保留**地切开。切完的每个凸胞元因此整体落在 B 内、
   B 外、或**恰好落在 B 的边界上** —— BSP 叶分类那个歧义在这里不可能出现；
3. 沿胞元法向在 `±delta` 处做**绕数（winding number，立体角求和）内外探针**，得到四类：
   外、内、材料在法向背侧（`behind`）、材料在法向侧（`front`）；
4. 按集合运算取类（并=`first:外/behind`+`second:外`；交=`first:内/behind`+`second:内`；
   差=`first:外/front`+`second:内 翻向`），焊接、缝合 T 型接点、校验。

三处必须点名的工程细节：

- **共面胞元不能丢**。切分时"整片落在切平面内"的胞元最初被两端都丢弃，结果切面整片消失
  （实测 296 条边界边）；改为归入 front 侧保留，由探针分类决定去留。
- **T 型接点必须缝合**。两个操作数各自三角化，切口穿过圆柱侧面**四边形对角边**时会在接缝
  上引入一个顶点，而另一侧是平面切口，对此一无所知；焊接救不了（共线不共点）。`_stitch_t_junctions`
  把持有长边的那一侧在侵入顶点处切开。代价是面数上升（贯穿孔案例最终 3184 面）。
- **探针距离是契约不是细节**：`delta = 1e-6 x 模型尺度`。比这更薄的薄壁/近切特征不在保证
  范围内 —— 无任何有限精度谓词能把胞元与它所在的曲面分开，这一条写在模块 docstring 里。

## 4 注意点（踩过的坑 / 局限）

- **BSP/`csg.js` 不能直接收**：共面部分重叠是它的结构性缺陷，不是调参能修的（本单实测 300
  边界边的反例在案）。这是本单最有复用价值的否定性结论。
- **缝合后会有细长面**：缝合可能把面切成零面积碎片，必须丢（`area_eps`），否则校验不通过。
- **代价**：面数显著膨胀（贯穿孔 12+196 输入 → 3184 输出面），因为胞元是按切割
  平面排布切开的。对 BEM 面板网格这种"宁少宁整齐"的下游，应在布尔后再跑一次网格清理/合并。
- **未支持的配置（honest FAIL，不掩盖）**：圆柱与立方体的**非齐平**相交（差/并/交）三例目前
  **显式抛错**，不给非法网格。测试 `test_unsupported_configurations_never_return_an_invalid_solid`
  把这条固定下来：在缺陷修好之前，它们必须继续抛错；修好后该测试会失败，届时改判为 PASS 并
  更新本表。病因判断：探针在薄胞元上取点、以及缝合的扇形三角化对凹多边形不成立，需要按胞元
  内点（而非顶点均值）与更细的接缝处理重做。

| 齐平贯穿孔体积 | 解析 18-2π | 1.530e-03 | **是**（差异来自 48 段离散 2.85e-03，非布尔误差） |
| 拓扑（chi/亏格/壳数） | Euler 示性数精确判定 | 全部一致 | **是**（0 例不符） |
| 圆柱-立方体非齐平相交 3 例 | —— | 未给出结果（显式拒绝） | **否（不适用）**，如实记为未覆盖 |

GAP-CAD-003 判据原文要求"≥20 组共面/近切/退化夹具 + 体积误差 <1% + 失败显式报错"。
本单实测 **12 组**（夹具数未达 20，如实登记），体积与拓扑判据达标，显式报错判据达标；
**未达 20 组**，且非齐平相交类别仍拒绝 —— 这两条是本单的未完成部分。
