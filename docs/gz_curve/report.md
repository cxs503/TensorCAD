# Righting arms at finite heel: GZ(φ) against closed forms

TensorCAD 0.20.0 — `tensorcad.heel`. Generated by `python examples/gz_curve/run_example.py`; every number below is read from `results.json`.

## 1. What is measured

The submerged body below a tilted plane is built by clipping every triangle against `u·r ≤ c` and summing signed tetrahedra with the apex **on the water surface**, so the waterplane lid contributes exactly zero. Volume and first moment are therefore exact for the polyhedron; the only remaining error is the 1-D solve for `c` that holds the displacement constant.

- barge: L = 20.0 m, B = 6.0 m, T = 2.0 m, depth = 4.0 m, KG = 2.00 m; deck edge at 33.69°; ∇ = 240.0000 m³.
- shallow barge: same L/B/T, depth 3.0 m, KG = 2.20 m; deck edge at 18.43°.
- sphere: R = 1.00 m, draft = 0.6 R, KG = 0.30 m, 24-ring mesh (2208 facets).

## 7. What this does not do

- No free-surface correction: tanks are a loading property, not a shape one.
- No damage stability, no wind/launching heeling moment, no class rule.
- `G` is on the centreline; an off-centre `KG` needs a transverse `y_G` input.
- The closed body *is* the hull: a mesh capped at the design waterline has zero freeboard and raises `HeelError` instead of returning a number. Computing a ship's GZ needs the body closed at the deck.
- Angles are sampled, so `vanishing_angle_deg` is a linear interpolation between two samples (and `None` when the curve has not crossed by the last sample).
