# DTMB 5415 parametric reconstruction (Zenodo 9001 × 27)

`tensorcad.dtmb5415` rebuilds the **parametric map** from the Zenodo design-space
benchmark dataset (Serani, Palma, Wackers, Quagliarella, Gaggero, Diez; *Engineering
with Computers*, 2025). The dataset publishes **9001 configurations** of the DTMB 5415
hull, each as 2250 surface points plus the **27 normalised design variables** that
generated it. What it does *not* publish is the parametric model itself: the map
`design variables → geometry` has to be recovered from the data.

This module is that recovery, in the form TensorCAD needs: a callable whose input is
the 27-vector `v` and whose outputs are the point cloud, a triangulated surface mesh,
hydrostatics, and the **analytic derivative of each with respect to `v`**.

| source SHA256 | `16b14ba598787eeed74eb6a10e9ea6fb701bd25496b5ccbf8a317ad6e364bee2` |

The 2250 points of one configuration are a structured grid: two patches (fore body
bow→midship, aft body midship→transom), each with 25 girth stations (deck edge →
centreline) and 45 longitudinal stations. The published flattening order is
`index = 45 × (2 × j + patch) + i`.

## Reconstruction method

The design space is a **modal displacement field** over the baseline grid:

```
d(v) = Φ · (C₂ · [v, vech(v vᵀ)])
P(v) = P_ref + d(v)
```

| symbol | shape | meaning |
|---|---|---|
| `Φ` | 6750 × 40 | displacement PCA basis (captures 97.84 % of variance) |
| `C₂` | 40 × 405 | least-squares coefficients (27 linear + 378 quadratic terms) |
| `P_ref` | 2250 × 3 | baseline cloud (column 0 of the database) |
| `v` | 27 | normalised design variables in [−1, 1] |

The quadratic lift (`vech(v vᵀ)`, 378 distinct terms) is needed because the dataset
README states the generating model is nonlinear. The shipped model achieves **0.252 m
RMS** (2.45 % of beam) on a held-out split, compared to 0.406 m for a purely linear
fit and 0.883 m for the baseline alone.

### Mesh generation

The surface mesh is a bicubic (natural) spline interpolation of the two structured
patches in their `(girth, station)` index space, refined to **49 × 133** per patch,
mirrored to the port side about `y = 0` and stitched across the patch seam. The
refinement and mirroring are **fixed linear operators** (the knots sit on the baseline
index grid and never move), so:

```
vertices(v) = L · P(v) = L · P_ref + (L · Φ) · (C₂ · [v, vech(v vᵀ)])
```

is affine in the modal amplitudes and its Jacobian is exact. The geometry is
differentiable by construction, not by finite-differencing a CAD kernel.

### Symmetry-plane restoration

`y ≥ 0` on the starboard side is a **hard geometric constraint** of a hull. The
data-recovered displacement field does not preserve it: at the stern the surrogate
undershoots the near-centreline `y` tail by up to ~0.3 m, so the interpolated surface
can cross the symmetry plane and the mirrored mesh folds through itself.

The pipeline applies an explicit **feasibility restoration**:

```
grid_feasible = max(grid_raw, 0)          # Euclidean projection, minimal norm
```

which moves only the offending coordinate, in the offending direction, and makes the
constraint hold *by construction* for every `v`. `station_grid()` returns the feasible
grid; `raw_station_grid()` returns the unprojected one, and `quality()` reports both,
so the restoration can never hide how far the surrogate overshot.

The projection is piecewise affine, so `vertex_jacobian()` carries the same 0/1 mask
and stays exact wherever the active set does not switch.

## What the derivative is, and is not

| method | differentiable? | notes |
|---|---|---|
| `vertex_jacobian(v)` | ✅ exact a.e. | carries 0/1 mask for clamped vertices |
| `volume_gradient(v)` | ✅ exact | shell volume to deck edge, matches central difference to round-off |
| `hydrostatics(v)` | ❌ | waterline clip is piecewise smooth; derivative jumps at sections crossing the plane |

The chain is intact through geometry → mesh → integral, and bypassed only at the
waterline clip; that gap is reported rather than hidden.

## Model accuracy (holdout split)

| model | holdout RMS (m) | holdout RMS (% beam) |
|---|---|---|
| M0 (baseline only) | 0.883 | 8.60 % |
| M1 (linear) | 0.406 | 3.95 % |
| M2 (quadratic) | 0.243 | 2.36 % |
| **M3 (PCA + quadratic, shipped)** | **0.252** | **2.45 %** |

The shipped model (M3) uses a 40-mode PCA basis with quadratic feature lift. The
slight increase from M2 to M3 is the cost of dimensionality reduction: 40 modes capture
97.84 % of variance, trading a small accuracy loss for a compact representation.

## Usage

```python
from tensorcad.dtmb5415 import DTMB5415Space

space = DTMB5415Space()

# Reference hull (v = 0)
v0 = space.zero()
mesh = space.mesh(v0)              # tensorcad.geometry.Mesh
verts = space.vertices(v0)         # (N, 3) numpy array
faces = space.faces()              # (M, 3) numpy array

# Hydrostatics at design waterline
hydro = space.hydrostatics(v0)
print(f"Displacement: {hydro['displacement_volume_m3']:.1f} m³")
print(f"Cb: {hydro['cb']:.4f}")

# Analytic gradient
grad = space.volume_gradient(v0)   # 27-vector, d(shell volume)/dv

# Quality report
q = space.quality(v0)
print(f"Vertices: {q['n_vertices']}, Faces: {q['n_faces']}")
print(f"Min angle: {q['min_angle_deg']:.1f}°")
print(f"Half-breadth raw min: {q['half_breadth_raw_min_m']:.6f} m")
print(f"Half-breadth clamped: {q['half_breadth_clamped_vertices']} vertices")
```

### Design vector from the database

```python
import scipy.io as sio
from tensorcad.dtmb5415 import DATASET

mat = sio.loadmat(DATASET["source_file"], variable_names=["variablesMatrix"])
v = mat["variablesMatrix"].T[430]   # configuration 430

space = DTMB5415Space()
mesh = space.mesh(v)
hydro = space.hydrostatics(v)
```


## Limits

* **Design domain**: the model is validated for `v ∈ [−1, 1]²⁷`. Extrapolation beyond
  this range is not guaranteed; uniform samples in `[−1.2, 1.2]²⁷` pass the geometry
  gate but accuracy degrades.
* **Surrogate error**: holdout RMS ~0.25 m (2.45 % of beam). The worst configuration
  has a maximum point error of ~4.6 m. This is the intrinsic limit of a data-recovered
  quadratic surrogate.
* **Symmetry-plane projection**: the `y ≥ 0` constraint is enforced by Euclidean
  projection, which is piecewise affine. The Jacobian is exact a.e. but has a kink at
  the active-set boundary (a measure-zero level set of a linear functional of `v`).
* **Waterline clip is not differentiable**: `hydrostatics()` does not provide gradients
  because the waterline intersection is piecewise smooth. The shell volume functional
  (`volume()`) is fully differentiable.
* **No appendages**: the DTMB 5415 has sonar domes, skegs, and a transom. The
  parametric model captures the main hull; appendages are not included.
* **No B-rep/STEP**: the output is a triangulated mesh. Industrial CAD exchange requires
  the OCP backend (not yet integrated).
