# Closed-form hydrostatics of the parametric hull

`tensorcad.hull.analytic_hydrostatics` returns the hydrostatics of the *analytic
surface* the generator samples, as the same `Hydrostatics` record the mesh path
returns. It exists so that sampled numbers have something to answer to: before it,
`compute_hydrostatics` was pinned against a unit box — whose tetrahedra integrate
exactly — and against nothing else. The generated hull is the first case with a
curved surface, a keel singularity and a waterline cap, and its only reference was
a finer copy of itself.

The reference is not a measurement, an experiment or a class-rule calculation. It
is the exact value of the surface the code claims to have generated, so the gap it
reports is *discretisation*, not modelling error.

## Where the closed forms come from

The sampled surface factorises. With `w = (z + T)/T` on `[0, 1]` and
`p = BREADTH_EXPONENT = 0.7`,

    y(x, z) = (B/2) * sin(pi*x/L)^p * sqrt(w)

so every volume integral splits into an `x` integral and a `w` integral, and both
have closed forms. `TAPER_INTEGRAL` is the Beta function
`int_0^1 sin(pi*x)^p dx = Gamma(0.85)*Gamma(0.5) / (pi*Gamma(1.35))`.

| Quantity | Closed form | Where it comes from |
|---|---|---|
| Displacement volume | `L*B*T*TAPER_INTEGRAL*2/3` | the `w` integral is `int sqrt(w) dw = 2/3`, times two sides |
| Waterplane area | `L*B*TAPER_INTEGRAL` | the cap is single-valued in `x`; the taper integrates to `TAPER_INTEGRAL` |
| Midship section area | `2/3*B*T` | taper is 1 at midship; the section integral is `int sqrt(w) dw * B*T` |
| LCB, LCF | `L/2` | the taper and the waterplane breadth are symmetric about midship |
| VCB | `-2/5*T` | `int (w-1)*sqrt(w) dw / int sqrt(w) dw = (2/5 - 2/3)/(2/3) = -2/5`, taper cancels |
| Block coefficient | `2/3*TAPER_INTEGRAL` | `V/(L*B*T)` |
| Prismatic coefficient | `TAPER_INTEGRAL` | `V/(L*A_midship)`; the midship `2/3` cancels exactly |
| Wetted surface area | quadrature | no elementary antiderivative; see below |

The wetted area is the one quantity without a formula. Its surface element,

    |P_x x P_w| = sqrt(T^2 + (T*B/2*s'(x)*sqrt(w))^2 + (B/2*s(x)/(2*sqrt(w)))^2)

has a `1/sqrt(w)` keel term and an `x^(p-1)` bow/stern tip slope, so
`analytic_wetted_surface_area` substitutes `w = u^2` and `x = L*psi/pi`,
`psi = (pi/2)*tau^3` to make the integrand smooth, then applies an 80-point
Gauss-Legendre rule in `(tau, u)` (nodes from Newton iteration on the Legendre
polynomial; the core stays standard-library only). Refining to 120 nodes changes
the value by `< 1e-9` relative, three orders below the mesh error it is compared
against.

## How the reference is itself checked

A formula checked only against itself proves nothing, so both quadrature families
are run against each other and the closed forms are run against numerical
integration of the same integrands:

* `TAPER_INTEGRAL` against a Simpson rule in `theta` (substituting
  `x = (1-cos theta)/2`, without which the `x^0.7` tip makes Simpson converge only
  algebraically): `5.6e-13` relative;
* the wetted area, Gauss-Legendre vs a Simpson product rule on the same element:
  `6.0e-09` relative;
* volume, waterplane area, midsection area and VCB against Simpson quadratures of
  the separate `x` and `u` integrals, to `1e-11`;
* homogeneity: doubling `L`, `B` and `T` multiplies the wetted area by exactly 4.

`tests/test_analytic_hydrostatics.py` pins all of the above, plus the signs,
which are part of the claim.

## What the sampled surface actually gets wrong

The full table is generated by
`python examples/analytic_hydrostatics/run_analytic_check.py` (writes
`docs/analytic_hydrostatics/{results.json,report.md,convergence.png}`; every number
in it is written straight from the computation). The claims that script gates on,
and that the test suite pins:

* at the shipped default grid `41x13` every quantity is within **3 %** of its
  closed form; the worst are the block coefficient and the volume at `-0.88 %`,
  the VCB at `+0.94 %` and the midship section area at `-0.71 %`;
* at `161x41` every quantity is within **0.2 %**; the volume error is `-0.136 %`,
  the same number the first audit read off the README, now with a closed-form
  baseline behind it instead of a second mesh;
* the error falls monotonically in `h` for volume, waterplane and wetted area;
* the sign is negative wherever the error is a length-, area- or volume-weighted
  sum: the chords between stations cut **inside** the analytic surface, so the
  sampled hull under-reports. A positive volume error would mean the lofting
  overshoots, which it cannot do with a chordal approximation and would therefore
  be a defect rather than a refinement level;
* the VCB is the exception and comes out **high** (`+0.94 %` at the default grid):
  the trapezoidal section rule over-estimates the breadth near the keel, where the
  `sqrt` profile is steepest, which raises the centroid;
* LCB and LCF land on `L/2` to `1e-9 m` at every resolution. That is a symmetry
  consequence and it validates the frame and the sign conventions of the `x`
  moments, not an asymmetric loading — see the limitations.

## The discretisation estimator is optimistic

`estimate_discretisation_error` reports the relative change between the requested
grid and a uniformly refined one, and calls it "an error estimate for the coarse
grid". The closed form says how optimistic that is at `41x13`: the measured error
is **1.53x** the reported change for volume, **1.77x** for wetted area and
**1.44x** for waterplane area. The ratio is consistent with the observed
convergence, which is between first and second order because of the tip
singularities, so the estimator is a useful indicator and not an error bound.
`analytic_relative_errors` returns that comparison under
`outside_discretisation_estimate` so the gap travels with the numbers instead of
living in this page.

## Limitations

* **One hull form.** The family is `sin(pi*x/L)^0.7 * sqrt((z+T)/T)`, symmetric
  fore and aft, no transom, no bulb, no appendages. The reference is exact for that
  surface and says nothing about a real vessel's resistance, stability or class
  compliance. There is no experimental or literature comparison to make here: the
  surface is a synthetic form, so the only meaningful baseline is its own
  analytic definition.
* **LCB/LCF are trivial.** `L/2` follows from symmetry. The test still earns its
  keep (frame and sign of the `x` moments, waterline cap included), but it cannot
  detect an antisymmetric bias, because the geometry has none. An asymmetric
  variant of the family would be needed for that.
* **Wetted area is quadrature, not a formula.** Its accuracy (`< 1e-9`) is
  established by two independent quadrature families, not by an external source.
* **The waterline is a plane at `z = 0`.** The reference assumes the design
  waterline; a trimmed or heeled condition is outside the model, as it is for
  `compute_hydrostatics`.
* **Density is an input, not a derivation.** 1025 kg/m³ is seawater by convention;
  1000 is fresh.
