# GAP-CAD-T1-IGES-PIPE — KVLCC2 的 −17.9 % 是「路线」的账，不是「几何」的账（m23282）

**Anchor** `GAP-CAD-T1-IGES-PIPE` · **Mission** m23282 · **Repo** TensorCAD · **Branch** agent/m23282
**本轮范围**：把 KVLCC2 上两条互相矛盾的体积路线（+312 568 m³ / −0.017 % 与 256 657 m³ / −17.90 %）
的**分歧归因**做成可判定的算术，而不是再取一次平均。交付 = 闭式判据（已绿）+ 可复现测量工具（已交集群排队）。

## 1. 案例：同一个文件，两个数字差 18 %

| 路线 | 方法 | KVLCC2 ∇ | 对公开 312 622 m³ |
|---|---|---|---|
| A `fleet_baseline.build_ship` | 密集 in-trim 采样 → 水密网格 → 体积 | 312 568.0 m³ | **−0.017 %** |
| B `kvlcc2_divergence_probe`（m22903） | 逐片三角化 + 散度定理 `V=(1/3)∮r·n dA`，**未做定向修复** | 256 657 m³ | **−17.90 %**，闭包残差 `\|∮n dA\|=11 272 m²` |

m22903 由 B 推出「补片集不封闭/定向不一致 → KVLCC2 应改判 WITHHELD」。但 B 的前提本身有算术问题：
**出版方 IGES 交付的是「船壳皮」，不是「固体」**。中纵剖面盖与水线盖不在文件里（KCS 同样如此，
它的 `watertight` 一直是 false），所以 `∮n dA ≠ 0` 对任何船壳皮都成立，**它不能证明几何缺了一块**。

## 2. 怎么做的：先把这条账写成闭式（不需要 KVLCC2 也能判）

对半船皮用散度定理：

```
V_skin = V_half − (1/3)·T·A_wl        （唯一缺的盖是设计水线；中纵剖面盖 r·n = y = 0，贡献恒为 0）
∮_skin n dA = (0, +A_side, −A_wl)     （y 残差来自舷侧，z 残差来自缺失的水线盖）
```

新增 `tests/test_hull_surface_open_skin_cap.py`（5 项，全绿，0.6 s，纯解析无资产）：

| 断言 | 结果 |
|---|---|
| 开口半船皮的散度积分 = `V − (1/3)T A_wl`，相对误差 | **1e-12** |
| 补上 z 盖后：`V` 精确、`∮n dA` 的 z 分量为 0 | **1e-12** |
| 再补 y=0 盖：`∮n dA` 三分量全 0，体积**不变**（证明中纵盖只清残差、不带体积） | **<1e-12** |
| 同一条开口皮上 `hull_characteristics`（包络积分，不需闭包）→ 精确体积 | **1e-12** |
| 水线面积 ×2 → 缺口 ×2（缺口就是盖项，不是噪声） | 比值 2.000000 |

## 3. 对 m22903 数字的两处独立复核（只用它自己公布的表）

| 复核项 | m22903 记录 | 与「缺盖」解释是否自洽 | 判定 |
|---|---|---|---|
| z 残差 10 003.3 m² | 约等于「水线片两份之和 5 142.4×2 = 10 284.8 m²」 | 半船水线面积上界 = `Cwp·L·B/2 = 0.9·320·58/2 = 8 352 m²`，**10 003 > 8 352**，物理上不可能是水线面积 | 该 z 残差**不是**单一盖面积 → 路线 B 另有定向错误（未做 `orient_consistently`），不能用来给几何定罪 |
| 残差符号 | `(861.6, −5 123.1, +10 003.3)` | 正确外向的半船皮应为 `(0, +A_side, −A_wl)`：y、z 符号**同时反向** | 指向**整皮定向内向**（或混合定向抵消），与几何缺失无关 |

换句话说：路线 B 的 −17.9 % 与 11 272 m² 残差，**证据指向「未定向修复 + 未补盖」，而不是「补片集少了 18 % 的船」**。
这与路线 A 在**同一文件**上 −0.017 % 的结果不矛盾——正是可分离的两种账。

## 5. 注意点 / 局限

- 闭式部分只用了箱形皮：它证明的是**算术恒等式**（缺口 = 盖项），不是 KVLCC2 的数值结论；
  KVLCC2 的盖项大小取决于真实 `A_wl`，必须实测（第 4 节）。
- 路线 B 的补片三角化用「单元中心 even-odd」，边界单元 O(h)；m22903 已用 30/60/120 三档证明其对体积影响 <0.15 %，
  本文不重复该证明。
- 本工具对**定向**做 `orient_consistently` + 全局外向翻转；不改动任何曲面点，故不改几何。
- 出版方几何字节不入库（license），证据 JSON 只记文件名、sha256 与网格设置。
