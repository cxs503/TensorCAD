## 1. 案例介绍（物理背景 / 几何 / 参数）

曲面偏移（offset）与抽壳（shelling）是板壳结构生成的基础 CAD 操作：把封闭外表面沿法向内偏置 t 得到内表面，两者之间即壳体材料。船体领域用于双层底、舷侧板架、舱壁的板壳建模。

| 算例 | 几何 | 参数 | 解析参照（闭式） |
|---|---|---|---|
| 球 | UV 球 r=1.0 | t=0.1，网格 24x12 → 144x72 | 壳体积 4/3π(r³−(r−t)³)=1.1351621455；腔体积 4/3π(r−t)³=3.0536280593 |
| 方箱 | 1×1×1 | t=0.01/0.05/0.1 | 内体积 (1−2t)³，t=0.1 时 0.512 |
| 经典 Wigley | L=10, B=1, T=0.625, nx=40×nz=20（1522 顶点 / 3040 面） | t=0.01 | 无（要求"双面水密"） |
| 椭球船型 | a=5.0, b=0.5, c=0.3125（48×24，1106 顶点 / 2208 面） | t=0.02 | 无（要求"双面水密"+实测壁厚） |

## 3. 计算结果（程序化注入，零手抄）

### 3.1 球偏移体积（裁判项，容差 0.1 %）

| 分辨率 | 面数 | 壳体积（审计求积） | 壳误差 % | 腔体积误差 % | 实测壁厚 |
|---|---|---|---|---|---|
| 24x12 | 528 | 1.1173611081 | 1.5681 | 3.2891 | 0.100000 |
| 48x24 | 2208 | 1.1306964189 | 0.3934 | 0.8303 | 0.100000 |
| 96x48 | 9024 | 1.1340447425 | 0.0984 | 0.2081 | 0.100000 |
| **144x72** | **20448** | **1.1346654419** | **0.0438** | **0.0925** | 0.100000 |

审计者求积与被审模块 `ShellResult.shell_volume` 逐分辨率**四位一致**（1.5681 / 0.3934 / 0.0984 / 0.0438 %），报告数字非手抄、可复现。
收敛阶（按真实加密因子）= **1.99 / 2.00 / 2.00** → 报告"二阶"成立。
方箱（平面精确性）：t=0.01/0.05/0.1 内体积误差 **2.97e-12 / 3.05e-12 / 3.04e-12 %**（报告 <1e-12 量级成立，实际 3e-12）。

### 3.2 literal 验收式（4/3π(r+t)³，外向偏移）

| 分辨率 | 体积（内部核 d+t） | 误差 vs 5.5752798 % |

| 48x24 | 5.5409950617 | 0.6149 |
| 96x48 | 5.5666913528 | 0.1540 |

公开 API 只接受内向偏移：`shell(mesh, −0.1)` / `offset_inward(mesh, −0.1)` 均抛 `ShellError: the thickness must be positive and finite`。即 **mission 验收式字面上的外向偏移在交付接口里不可达**，被审报告实测的是其内向孪生式（腔体积 4/3π(r−t)³，0.0925 %）。

## 5. 注意点（审计发现，按严重度）

- **F1｜material｜验收第 2 条未兑现**：mission 写"Wigley 外壳抽壳双面水密"，交付是**拒算**并以椭球替代。拒算本身是诚实且正确的（零梁宽艏艉垂足任何内偏置都会自交），但替代算例不构成对该条的交付。
- **F2｜material｜可复现性**：PR #403 合并只带进 `repro_offset_shell.py` + `tests/test_offset_shell_gap.py`（2 个文件"被门禁滤除"= `artifacts/offset_shell/results.json`、`convergence.png`）。报告正文却以 `artifacts/offset_shell/...` 为工件指针 → 在仓库里点不到。
- **F3｜low｜归因不成立**：报告把 Wigley 拒算归给"龙骨 sqrt 奇点 m=2 与水线角点 n=2"。审计定位到唯一最差面在 x≈9.66、z≈−0.60~−0.625、\|y\|→0 的**零梁宽艏/艉垂足**；水线角点并未卷入。结论（不能抽壳）对，命名原因错。
- **F4｜low｜复现脚本不是机器裁判**：`repro_offset_shell.py` 打印 `[FAIL]` 但恒 `exit 0`；机器判据只能靠 pytest 套件。
- **F5｜low｜<0.1 % 与分辨率未绑定**：96x48 壳误差 0.0984 %（过）而腔误差 0.2081 %（不过）；验收线只 144x72 过，mission 未写网格分辨率。
- **F6｜info｜基准台账缺行**：`tensor_benchmark_cases` 对本锚点 0 行 → maturity_gate 无法用登记容差机器裁定，建议登记解析算例（ref 1.1351621455，tolerance <0.1 %，metric=壳体积相对误差）。
- **F7｜info｜集成面只有示例级**：`tensorcad/__init__.py:418` 导出；`examples/shelling/run_example.py`、`examples/midsurface/run_example.py` 使用；包内其他模块对 `tensorcad.shell` 仅文档字符串提及，**无求解器/平台调用方**。
- **F8｜info｜套件成本**：14 个测试 189.66 s（单机），进 CI 需标记 slow。
