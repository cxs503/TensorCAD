## ① 案例介绍（物理背景 / 几何 / 参数表）

**前五轮的结论**是两句话：500 船 100 % 通过 8 道质量门；第 5 轮证明这支门会对
网格级缺陷报警（翻一个三角形，`G4` 响）。**但这两句都只关于生成器**：
`tensorcad.shipd_population.build_shipd_database` 先抽 `Cb`，再由课本关系式导出 `Cm`/`Cwp`，
并在 `Cp = Cb/Cm > Cwp` 时**主动抬高 Cwp**（`cwp_adjusted`）；标定族 `cb_calibrated_sections`
又是照着这组系数反解出来的。也就是说，**生成器→重建→门 是同一个作者同一只手调出来的闭环**，
500 条船里不存在一条系数上不可实现的船，也不存在一条标定族表达不了的船。
一条通过率只有在**种群会失败**时才是证据。

**本轮补两个能失败的种群**：

1. **样本外**——仓内已有的 6 条公开基准船（`tensorcad/fleet/data/fleet_manifest.json`：
   KCS / KVLCC2 / ONRT / JBC / DTC / Series 60）。它们不是生成器的产物，是船厂与
   水池真在用的 workshop 标模，主尺度与系数不是为了这条管线好看而选的。
2. **强对抗**——`Cb`、`Cm`、`Cwp` 三个系数**独立**均匀抽样，不做 `Cp <= Cwp` 修复，
   于是种群中必然出现「水线面比棱形系数还瘦」这种描述不出任何船的参数向量。

**第三个前五轮从未测的量**：纵向浮心 `LCB`。它是每条真实船的主尺度要素之一，也是
MIT ShipD 输入向量的 45 个分量之一，但**不在本管线消费的 6 个标量里**
（`L, B, T, Cb, Cm, Cwp`）。下面把它和出版值并列报出来，而不是留在未测量状态。

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **独立测量，不信被判方的账**（`shipd_oos.mesh_volume_and_lcb`）：体积与浮心由三角面片
   用散度定理自算（每个三角形贡献四面体 `(0,a,b,c)`，体积 `a·(b×c)/6`，形心 `(a+b+c)/4`），
   `LCB` 以网格自身纵中点为基准、按 `|ΔLCB|/L` 报**绝对值**，因此不依赖生成器把 `x=0`
   放在艉垂线还是舯。门判定仍来自被判方 `rebuild_ship`，但**判决量不来自它**——
   这样它自己的体积记账出 bug 也没法藏在自己的门后面。
2. **语料即真相**（`literature_corpus`）：逐条保留 manifest 的 provenance，补 `Cp = Cb/Cm`
   与 `cp_le_cwp` 可行性标志。manifest 未给 `Cwp`，一律按 Schneekluth 回归 `(1+2Cb)/3`
   导出并标 `cwp_source="schneekluth_derived"`——因为它决定方法选择，这一层是我们加的，
   不是船的属性，报告里必须说清楚。
3. **判别力 2×2**（`discrimination_table`）：物理前提 `Cp <= Cwp` 由参数向量本身决定
   （先于任何几何），据此与「是否被管线接受」交叉成四格。两个非对角格是仪器的两种错误，
   都必须为 0，通过率才有意义。
4. **三populations同仪器**：in-sample 60 船（生成器，`seed=42`）作对照；样本外 6 船；
   强对抗 120 船（`seed=20261116`）。三组同网格同门集同方法偏好。
5. **失败模式分类账**（`classify_failure`）：拒绝（不可实现系数 / 窗口外）优先于指标超标（
   过了门但系数或湿表面积超 3 %）——一条没变成网格的船没有指标可超。

### 3.3 强对抗种群的判别力（2×2，这是通过率能否作证据的核心表）

| | 管线接受 | 管线拒绝 |
|---|---|---|
| `Cp <= Cwp`（物理可行） | 78 | 0 |
| `Cp > Cwp`（不可实现） | 0 | 42 |

* **假接受（不可实现却被判通过）= 0**：没有一条描述不出船的参数向量通过了门。
* **假拒绝（可行却被判失败）= 0**：可行三元组里没有一条被误杀。
* 该种群通过率 65.00%，即同一条管线在 120 条独立抽样上会否掉 42 条 —— **通过率是可失败的**，不是恒真式。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **ONRT 这条船暴露了两件事**。按 manifest 记录的 `Cb=0.535, Cm=0.75` 推 `Cp=0.713`，
   而 Schneekluth 导出的 `Cwp=0.690` —— **水线面比棱形系数还瘦，这条参数向量描述不出船**。
   管线没用标定族（`_calibrated_feasible` 判否），回落到 `parametric_sections`，该族忽略
   `Cb/Cm`，造出体积差 13 % 的曲面，被 `G6_volume_consistency` 拦下。两个结论都要写清：
   ①门这次是有效的（不是静默通过）；②但拒绝是靠体积门**间接**发生的，不是显式 `REFUSED`，
   且 manifest 里 ONRT 的 `Cm=0.75` 与公开值（约 0.98）不符，属**待复核的转录疑点**，
   本轮不擅自改数（不改被判方的账，留作 `GAP-CAD-T1` 侧核对项）。
2. **`LCB` 是全族缺项，不是可修的小偏差**。族艏艉对称 → `LCB≡0`。`Cm/Cwp` 可忠实地还原，
   浮心不能。经验上 `1 %L` 的浮心错位大致对应百分之几量级的阻力变化（量级判断，非本文实测），
   所以 KVLCC2 的 3.48 %L 已经落在「不能拿去做阻力/耐波输入」的一侧。
3. **`Cwp` 是我们导出的**（manifest 未给）。它参与方法选择，所以「某条真船被拒」可能是我们的
   回归造成的假拒绝，而不是船的属性。样本外 6 条里没有出现这种情况（假拒绝 = 0），但这只证明
   这 6 条没撞上，不证明以后不会。
4. **`LCB` 符号约定**：manifest 按 `tensorcad.fleet.lcb_frames` 的规范帧读（`%Lpp`，正为艏向，
   自 `Lpp` 舯点）。不同出版方符号不同，所以本文只报 `|ΔLCB|`，以量级论；若约定不同，
   结论（缺项导致 3.48 %L 量级错位）不变。
5. **样本外只有 6 条船**，不能当分布用：逐条列出、不给均值意义以外的统计推断。强对抗种群是
   合成的（独立均匀抽样），它检验的是**管线的判别力**，不是任何真实船队的构成。
6. **本轮开工时主干是 RED 的**：`tests/test_shipd_audit.py::test_documented_blind_spot_single_inverted_triangle`
   在第 5 轮把 `G4` 硬化之后仍在钉「翻一个面十门皆哑」这个旧事实，于是必然失败
   （它自己的 docstring 就写着「若此测试失败，说明有门获得了该能力，审计报告须更新」）。
   已按该指令改钉**闭合后的**事实（`undetected_defects == []`、且必须是 `G4` 报而非 `G6` 报），
   并在测试里写明为何 `G6` 命中不算证据。教训：审计产物里的「已知缺陷」断言必须与修复同批翻转。
7. **MIT ShipD 30k 仍然无法采样**（无网络、`data/raw/shipd/` 空）。所以「样本外」只能做到
   文献基准船 + 对抗种群；真正的 `GAP-CAD-C2-SHIPD-REALDATA` 仍需数据落地。

## ⑥ 误差判定（逐项 vs 基准，显式回答「是否 < 3 %」）

| 关键量 | 基准 | 本轮实测 | < 3 % ? |
|---|---|---|---|
| 体积/Cb（文献样本外，过门者） | `Cb·L·B·T` | 最大 0.000%（5 条过门船） | **是** |
| 体积/Cb（ONRT，被拒） | `Cb·L·B·T` | 13.01% | **否**（`G6` 已拦） |
| 体积/Cb（强对抗种群） | 同上 | 平均 1.997%，最大 46.53% | 过门者**是**，全体**否** |
| `LCB`（KVLCC2，唯一可对拍的出版值之一） | 出版 3.48 %L | 网格 0.000 %L ⇒ `|ΔLCB|=3.48 %L` | **否** |
| `LCB`（KCS） | 出版 1.48 %L | `|ΔLCB|=1.48 %L` | **是**（数值上，但属巧合：族恒为 0） |
| 湿表面积（文献样本外） | Holtrop & Mennen 1982 | 平均绝对 2.07%，最大 3.57% | 平均**是**、最大**否** |

**是否 < 3 % 的直答**：

* 系数层面（体积/`Cb`）—— 过门的船 **是**，最大误差在 1e-3 量级；被拒的船不该算通过。
* 湿表面积 —— 平均**是**、最大**否**：平均绝对 2.07%，最大 3.57%，
  与第 5 轮一致（形状族差异，非网格误差），本轮不粉饰。
* `LCB` —— **否**，且这不是精度问题而是**缺项**：族里没有这个自由度，KVLCC2 差 3.48 %L。
* 通过率本身 —— 可失败（强对抗 65.00%），假接受 0 条、假拒绝 0 条。
