## 1. 案例介绍

### 1.1 物理背景

在船舶总体性能计算管线中，几何模型需要在不同求解器之间交换。每个求解器支持的网格格式不同：
- **STL**：3D 打印/快速原型标准，facet soup 无拓扑
- **OBJ**：Wavefront 格式，广泛支持的表面网格
- **VTK**：科学可视化标准，ParaView/VisIt 读取
- **SU2**：开源 CFD 求解器原生格式
- **CGNS**：CFD 通用数据系统标准（SIDS/HDF5）
- **Gmsh**：开源网格生成器格式

本工作验证 TensorCAD 原生六格式读写器的往返保真性：同一几何体写入某格式后读回，体积、拓扑、取向必须保持不变。

### 1.2 测试几何体

| 几何体 | 类型 | 解析体积 | 顶点数 | 面数 | Euler 示性数 |
|--------|------|----------|--------|------|-------------|
| cube | 凸多面体（genus 0） | 8.0 m³ | 8 | 12 | 2 |
| icosphere2 | 球面近似（genus 0） | 4.047005 m³ | 162 | 320 | 2 |
| torus64x32 | 环面（genus 1） | 1.762302 m³ | 2048 | 4096 | 0 |

**解析体积基准**：
- cube: $V = a^3 = 2^3 = 8.0$ m³（精确）
- icosphere: $V \to \frac{4}{3}\pi r^3 = 4.188790...$ m³（subdivision=2 时 4.047005 m³）
- torus: $V = 2\pi^2 R r^2 = 2\pi^2 \times 1.0 \times 0.3^2 = 1.776529...$ m³（离散化 64×32 时 1.762302 m³）

### 1.3 格式特性

| 格式 | 精度 | 拓扑 | 特殊约束 |
|------|------|------|----------|
| STL | float32（格式定义） | facet soup，需焊接 | 法向量需与顶点绕向一致 |
| OBJ | float64（17位有效数字） | 显式索引 | 1-based 索引 |
| VTK | float64 | UNSTRUCTURED_GRID | 默认 dialect 需 meshio 可读 |
| SU2 | float64 | NELEM 块 | 三角形类型 ID=5 |
| CGNS | float64 | SIDS/HDF5 | 需 CGNSLibraryVersion 节点 |
| Gmsh | float64 | MSH 2.2 ASCII | 三角形类型 ID=2 |

## 2. 方法

### 2.1 工具链

- **写入器**：`tensorcad.mesh_formats.write()` — 原生六格式写入器，不依赖 meshio
- **读取器**：`tensorcad.mesh_formats.read()` — 原生六格式读取器，从格式规范编写
- **比较器**：`tensorcad.mesh_formats.compare_meshes()` — 几何+拓扑+取向比较
- **验证器**：`tensorcad.mesh_formats.sids_violations()` — CGNS SIDS 合规性检查

### 2.2 往返流程

```
原始 TriMesh → write(fmt, path) → 磁盘文件 → read(path, fmt) → 读回 TriMesh → compare_meshes()
```

### 2.3 比较不变量

`compare_meshes()` 验证以下不变量：
1. **顶点双射**：读回顶点集与原始顶点集存在一一映射（float64 格式要求精确匹配）
2. **面数相等**：输入/输出面数相同
3. **面多重集相等**：面的索引集合相同
4. **有向面多重集相等**：面的取向（顶点顺序）相同
5. **体积符号相等**：体积正负号不变（外向法向保持）
6. **封闭性**：读回网格无边界边

### 2.4 容差设置

- STL：`tol=1e-5`（float32 精度限制）
- 其他格式：`tol=0.0`（要求精确双射）

## 5. 注意点

### 5.1 STL 精度限制

STL 格式本身定义为 float32，因此往返后顶点坐标有 ~7 位有效数字的精度损失。对于 icosphere2（半径 1.0），最坏相对误差为 4.58×10⁻⁹，远低于验收阈值 1e-5。对于大尺度模型（如 1000 m 船体），float32 的绝对误差约为 10⁻⁴ m，需在应用层注意。

### 5.2 STL 是 facet soup

STL 不存储拓扑信息，每个面独立存储三个顶点坐标。读回后需要焊接（weld）才能恢复拓扑。本模块的 `weld()` 函数通过舍入不变量焊接，decimals=12 时能正确恢复原始拓扑。

### 5.3 CGNS SIDS 合规性

本模块写入的 CGNS 文件包含完整的 SIDS 元数据：
- `/CGNSLibraryVersion` 节点（R4 类型，值 4.3）
- `/Base` 节点（CGNSBase_t 标签）
- `/Base/Zone1/GridCoordinates` 节点（CoordinateX/Y/Z）
- `/Base/Zone1/GridElements` 节点（ElementType=5 for TRI_3）

`sids_violations()` 检查确认零违规。

### 5.4 SU2 格式选择

SU2 写入器默认使用 `nelem_mode="volume"`，将三角形放在 NELEM 块中。这是 meshio 可读的 dialect。`nelem_mode="boundary"` 也是合法 SU2，但 meshio 的 SU2 读取器有缺陷（`StopIteration`），因此不推荐。

### 5.5 VTK dialect 选择

VTK 写入器默认使用 `UNSTRUCTURED_GRID` 而非 `POLYDATA`。虽然两者都是合法 VTK，但 meshio 的 legacy VTK 读取器只接受 `UNSTRUCTURED_GRID`/`STRUCTURED_*`。`POLYDATA` 可通过 `dataset="POLYDATA"` 参数使用。

### 5.6 适用范围

- 本验证针对**表面三角形网格**（TriMesh）
- 体积网格（四面体）的 SU2/CGNS 往返由 `meshio_exchange` 模块单独验证
- 四边形/多边形网格的导入由 `format_conformance` 模块处理（扇形三角化）
