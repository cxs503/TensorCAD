# GAP-CAD-C2-SHIPD-REBUILD 第 8 轮：把 LCB 自由度接到 500 船总体重建上

> 锚点 `GAP-CAD-C2-SHIPD-REBUILD`。本轮接的是第 6 轮量出来的欠账：500 船重建
> （第 3/5 轮）与 6 条公开基准船（第 6 轮）的纵中浮心全部落在 `0.000 % L`，
> 而真实船不是 —— 参数向量里没有 LCB 这一项，门禁里也就没有这一项。第 7 轮把
> `lcb_offset` 做进标定族（35 例扫描，误差 ~1e-15 L），但**没有被管线消费**：
> `rebuild_ship` 不读 LCB，种群表没有 LCB 列，八道门不看浮心。
>
> 本轮新增：`tensorcad/shipd_population.LCB_FRACTION_RANGE` + `sample_lcb_fraction`（按船型的 LCB 抽样带）、
> `tensorcad/shipd_rebuild` 的 LCB 通道与 `G11_longitudinal_centre` 门、`run_shipd_rebuild(workers=...)`；
> 生成器 `tools/shipd_rebuild/run_round8_lcb.py`。工件：`runs/shipd_rebuild_r8/population/`、`runs/shipd_rebuild_r8/control/`、`runs/shipd_rebuild_r8/literature/summary.json`、`runs/shipd_rebuild_r8/bitwise.json`。
> 网格 `81x21`；本文数字全部由生成器从上述 JSON 读出，零手抄。

## ① 案例介绍（物理背景 / 几何 / 参数表）

浮心纵向位置 `LCB` 是主尺度要素，不是装饰：它决定阻力（首尾波系干涉）、
纵倾与操纵。舱内 fleet manifest 的公开值：KCS `-1.48 % L`、KVLCC2 `+3.48 % L`。
重建族 `cb_calibrated_sections` 的对称律 `g = sin(pi x/L)` 只能给出 `LCB = 0`，
因此第 3/5 轮那 500 条『系数精确』的船，每一条都有一条主尺度要素错了 1.5–3.5 % L。

本轮给参数向量加第 7 个分量 `lcb`（有符号、以 L 为单位、正=偏前），并按船型取服务区间：

| 船型 | LCB 抽样带 [% L] |
|---|---|
| container | -2.0 … -0.5 |
| tanker | +1.5 … +3.5 |
| bulk_carrier | +1.0 … +3.0 |
| general_cargo | +0.0 … +2.0 |
| roro | -1.0 … +1.5 |
| cruise | -1.5 … +0.5 |
| ferry | -1.0 … +1.0 |
| tug | -1.5 … +1.5 |
| naval_escort | -1.5 … +1.0 |
| fishing | -2.0 … +1.0 |

**取值来源与等级**：Watson《Practical Ship Design》第 2 章主尺度表、
Schneekluth & Bertram 第 2 章 LCB–Fn 关系图的**离线回忆**典型服务区间，
`verified=false`，不是拟合任何一条船。它足以检验控制回路（把浮心放到请求位置），
不足以支撑『这条船就是真船』。

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **管线接线**：`_rebuild_calibrated` 把 `ship['lcb']` 传进 `CalibratedHullParameters.lcb_offset`；`lcb` 缺省为 `0.0`，走第 3 轮对称路径，
   曲面逐位不变（见 3.4 的哈希回归）。
2. **不可达即拒**：`LcbRequestUnreachable` 单独捕获，判 `REFUSED`，
   错误串以 `lcb_unreachable:` 开头，失败账与网格缺陷分开记。`|lcb| >= 5 % L`
   在 `problems()` 阶段就被拒（声明式护栏，第 7 轮定）。
3. **新门 G11**：请求里带 `lcb` 时，用 `cb_sections.realised_lcb_fraction`
   （散度定理、四面体体积/形心，纯 Python，不看构造）量网格自己的浮心，
   与请求比较，容差 `0.005 L`（=0.5 %L，约为第 7 轮最差实测误差的 500 倍）。
   门只在**参数向量明确请求 LCB** 时启用：老链条（Series 60 / Wigley / 参数化截面）
   没有 LCB 自由度，被请求时报 `unsupported` 而不是默默放行。
4. **两跑对照**：`population` 500 船带 LCB；`control` 同一 500 船**剥掉 LCB 列**，
   即第 3/5 轮配置，在本树重跑，使通过率逐行可比（同一网格、同一门集）。
5. **样本外**：6 条公开基准船按**各自出版 LCB** 重建（第 6 轮只测不控）。
6. **哈希回归**：20 条样本船，`lcb` 缺失 vs `lcb = 0` 两次重建比较顶点/面哈希。
7. **并行**：`run_shipd_rebuild(workers=128)` 进程池，每船独立，
   汇总与工件与串行一致（41x13 上串/并两跑 evidence 逐字段相同，见 tests）。

### 3.7 不可达探针（让『LCB 不可达』这类失败真的发火）

抽样带全部落在第 7 轮测出的可达包线内，因此 500 船里**没有**一条 LCB 不可达。
空的失败类别只有在它能响时才有意义，所以把 `Cb` 最大的 3 条船的 LCB 请求
推到 API 护栏边缘（`+0.0490 L`）：

| ship_id | 船型 | Cb | 几何可达上限 [%L] | 请求 [%L] | 判定 | 与实测上限一致 |
|---|---|---|---|---|---|---|
| 22 | tanker | 0.8596 | 4.653 | +4.900 | REFUSED | 是 |
| 482 | tanker | 0.8596 | 4.653 | +4.900 | REFUSED | 是 |
| 442 | tanker | 0.8587 | 4.688 | +4.900 | REFUSED | 是 |

读数：3 条中 3 条被拒、0 条被兑现；
其中 3/3 条的判决与`cb_sections.lcb_reach` 独立测出的几何饱和一致（请求 > 饱和 时就该拒）。
被拒的船**没有产出网格**，也没有产出系数误差 —— 拒绝发生在几何之前，这是该路径的设计。

### 3.8 可失败性：LCB 拒绝路径在包线内到底会不会响

3.1 的 500 船全部兑现。空的失败类别只有在它能响时才有意义，所以本轮做了两件事：
先跑一个**对抗种群**（LCB ~ U(-5 %, +5 %) L，与 `Cb` 无关，`seed=20261116`），再派一个**几何可达性普查**去核对拒绝边界。

| 量 | 值 |
|---|---|
| 对抗种群请求 LCB 的船 | 500 |
| 兑现（G11 通过） | 499 |
| 不可达被拒 | 1 （前倾 0 / 后倾 1） |
| 兑现者最差绝对误差 | 5.606e-05 L |
| 抽查船数（可达性普查） | 63 |
| API 护栏 | ±5.00 % L |
| 几何可达上限最小值 | 前倾 5.38 % L / 后倾 -13.67 % L |
| 护栏落在几何可达之外 | 前倾 0 条 / 后倾 0 条 |

**如实结论**：对抗种群 1 条被拒（500 条请求中）。拒绝路径没有坏 —— 3.7 的探针把请求推到 `+4.90 % L` 时确实触发拒绝，且拒绝消息里的饱和值与独立普查一致；对抗种群只多出这一条，说明「更重要的约束不是几何」。
原因是**在 ±5 % L 的 API 护栏内，几何几乎总是更宽**：抽样普查的几何可达上限最小值为
前倾 5.38 % L / 后倾 -13.67 % L，
护栏先于几何成为约束。也就是说：

- 在种群尺度上，**限制 LCB 可达性的主要不是几何，而是我们自己定的 5 % L 护栏**；
  因此 `LCB_UNREACHABLE` 在护栏内是低概率事件（带型典型 LCB 的种群 0/500，与 Cb 无关的对抗种群 1/500）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **LCB 是控制回路，不是型线。** 倾斜只移动体积纵向分布，不带球鼻、方尾、外飘、
   折角水线，也不控制 LCF。命中 `LCB` 不等于画出那条真船。
2. **LCB 抽样带是离线回忆的典型区间**（`verified=false`）。它只保证『请求落在
   真实船会出现的位置上』，不保证任何一条船的业务正确性。
3. **可达性受系数约束**（第 7 轮 3.3）：`Cb` 越大、带龙骨升高时可达带越窄。
   种群中触到边界的船被记为 `LCB_UNREACHABLE` 拒，不返回一条浮心不对的船。
4. **老链条明确不支持 LCB**：Series 60 / Wigley / 参数化截面被请求 LCB 时 G11 报
   unsupported，严格判定为 FAILED（见 3.5 中 `cp_le_cwp=否` 的船）。这是如实标注，
   不是新缺陷 —— 它本来就没有这个自由度。
5. **门容差是政策数字**（0.5 %L）。报告里同时给实测误差（3.1 末三行），
   门只负责判决。
