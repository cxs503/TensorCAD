## Seeding-formula audit

The node text quotes displacement as 4/3*L*B*T*Cb. With the naval-architecture block coefficient of the Wigley surface (Cb = 4/9) that expression returns 16/27*L*B*T, i.e. -25% against the closed-form volume 4/9*L*B*T; it equals the volume only for Cb = 1/3, which is not the block coefficient of this hull. The criterion is therefore evaluated in the standard form V = Cb*L*B*T with Cb taken from the geometry, and the literal expression is reported here for the audit trail.
