# CASE-LBM-KOVASZNAY-EXACT · 算例池条目：判据达成 + 误差归因定量改写

## ① 案例介绍
二维定常不可压 N-S 精确解（格栅后尾迹，y 向周期 1）：u=U0(1−e^(λx')cos2πy')，v=U0(λ/2π)e^(λx')sin2πy'，p=½U0²(1−e^(2λx'))，λ=Re/2−√(Re²/4+4π²)=**−0.9637405**（Re=40；旧任务书"λ≈−0.5"对应 Re≈78.46，为勘误）。
参数：| 项 | 值 |
|---|---|
| 格子/碰撞 | D2Q9/BGK |
| Re / U0 | 40.0 / 0.03（Ma_max=0.1039） |
| 域 | nx=3·ny，y 向周期；xmax∈[1,4] 扫描 |
| 入口 | 解析 Zou–He（库函数） |
| 出口 | 零梯度 Neumann（库函数） |
| 网格 | ny=32/64/128（nx=96/192/384） |
| 稳态 | 场漂移监测 + 末 100 步时间平均 |

## ② 怎么做的
新增算例池条目 `cases/kovasznay_2d/`：`analytic.py`（解析解 + **解析导数**核连续 N-S 残差作参考解证书）、`run.py`（`check|single|gate|study|ma`，带断点续跑缓存）、`make_report.py`（汇总+出图+自动生成 RESULTS.md，零手抄）。步进链 `collide_bgk→stream→零梯度出口→Zou–He 入口` 全为库内公开函数，float64。
三个单变量实验臂：**A** xmax 扫描（分离出口边界项）｜**B** 网格细化 ny=32/64/128（观测阶 p）｜**C** Mach 阶梯（固定网格固定 Re，U0 0.03→0.015→0.0075，分离 O(Ma²) 与 O(h²)）。

## ⑤ 注意点
1. "内部"必须剔除 ≥1 个 y 周期，只去 1 列（旧代码 `[1,nx−2)`）会保留整个出口边界层，造成"内部也差 2.5%"的误读。
2. xmax=1 时内部窗口退化为半域，仍被污染（v 内部 1.35%），此时不可用。
3. 掩模最大点相对误差在 v 零穿越处不可靠（m16861 已指出），判读一律用 L2。
4. 出口闭合备选（nscbc/NEE/解析 Dirichlet）均更差，见 m16974 负面结果，本单不重复。
5. 参考解证书升级：差分残差 ≈1e-3 → **解析导数残差 2.4e-15**（旧文档读起来像"参考解仅近似成立"）。

**是否 <3%：是**（判据量 2.5613%）。但 2.56% 中 **99.6–99.9% 是出口边界层**；内部离散精度 <0.12%，而内部误差由 **O(Ma²)=0.10%** 可压缩性底噪占据 ⇒ **PASS 不等于"已给出收敛阶"**（内部 p≈0）。要测收敛阶必须先解决 τ≲0.57 失稳（TRT/regularized 或体积力驱动全周期形式），列为后续建议条目。
