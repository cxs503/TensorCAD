# TensorCAD 高阶几何使能层 (High-Order Geometry Enablement Layer)

## 1. 案例介绍

### 物理背景
在高阶数值方法（DG/BEM/FEM）中，几何近似误差往往成为收敛瓶颈。当使用 p 阶多项式基函数时，如果几何仅用线性或低阶面片近似，则几何误差会主导整体误差，使得提高多项式阶数无法获得预期的收敛率。

### 几何定义
本模块提供三类参数化曲面：

| 曲面类型 | 参数化 | 解析面积公式 |
|---------|--------|-------------|
| 球面 (Sphere) | ξ→经度[0,2π], η→纬度[0,π] | 4πR² |
| 圆柱面 (Cylinder) | ξ→角度[0,2π], η→高度[0,H] | 2πRH |
| 环面 (Torus) | ξ→环向角[0,2π], η→极向角[0,2π] | 4π²Rr |

### 参数表
- 球面半径 R = 1.0, 2.0, 3.0 m
- 圆柱半径 R = 1.0~5.0 m, 高度 H = 0.3~10.0 m
- 环面主半径 R = 1.5~5.0 m, 次半径 r = 0.3~1.0 m

## 2. 方法

### 2.1 解析曲面求积
采用 p 阶张量积 Gauss-Legendre 求积公式：
- 在 [-1,1]×[-1,1] 上取 n×n 个求积点
- 映射到 [0,1]×[0,1] 参数域
- 权重包含 |∂S/∂ξ × ∂S/∂η| × 0.25（映射雅可比）

### 2.2 NURBS 曲面求值
采用 de Boor/Cox-de Boor 算法：
- 齐次坐标法处理有理基函数：C(u,v) = Σ wᵢⱼ Pᵢⱼ Nᵢ(u) Mⱼ(v)
- 商法则求导：S = C_xyz / C_w → dS = (dC·w - C·dw) / w²
- 二阶导数：d²S = (d²C·w² - 2·dC·dw·w - C·(d²w·w² - 2·dw²·w)) / w³

### 2.3 曲率张量计算
基于第一/第二基本形式：
- E = |S_ξ|², F = S_ξ·S_η, G = |S_η|²
- L = S_ξξ·n, M = S_ξη·n, N = S_ηη·n
- 平均曲率 H = (EN - 2FM + GL) / (2(EG-F²))
- 高斯曲率 K = (LN - M²) / (EG-F²)
- 主曲率 κ_max/min = H ± √(H² - K)

### 2.4 曲边单元接口
输出 `CurvedElementData` 结构：
- `element_id`: 单元标识
- `control_points`: 控制点坐标
- `quadrature_points`: 求积点（位置、法向、雅可比、权重、曲率）
- `metadata`: 元数据（求积阶数、点数）

## 5. 注意点

### 数值精度
- 球面/环面等含三角函数的曲面，4 阶求积仅达 ~1e-4 精度，需 8 阶以上达 1e-12
- 脐点（如球面）处 H²-K 理论上为零，浮点误差导致 ~1e-17 的判别式，需钳位处理

### NURBS 球面曲率
- `nurbs.py` 中的 NURBS 球面使用有理二次弧拼接，是球面的**几何精确但参数化不同**的表示
- 其曲率为常数但值为 -4（而非 1/R），源于参数化缩放
- 本模块的 `NURBSEvaluator` 正确复现了这一曲率

### 局限性
- 不支持裁剪曲面（trimmed patches）
- 不支持多片拼接（multi-patch stitching）
- 环面要求 r < R（标准环面）
- 球面/环面在极点处参数化退化（导数为零）
