## ① 案例介绍（物理背景 / 几何 / 参数表）

**物理背景**：船舶总体性能（阻力/推进/耐波/稳性/结构）全部以几何为输入。概念设计阶段拿到的是
参数向量 `(L, B, T, Cb, Cm, Cwp)`；要送求解器，必须先把它变成水密、流形、定向正确、且**体积等于
Cb·L·B·T** 的三角网格。这一步失真，后面所有学科的输入都失真。

**重建对象**：120 条船的参数表（`artifacts/shipd_rebuild/shipd_120.json`），
10 种船型（集装箱/油轮/散货/杂货/滚装/邮轮/渡轮/拖轮/军舰/渔船），
Cb 0.45–0.86，L 16–400 m。**诚实说明**：MIT ShipD 原始数据集本轮不可得（无网络、无本地副本），
本表是由 `tensorcad/shipd_population.py` 按公开设计空间区间（Watson《Practical Ship Design》
ch.2 主尺度表；Schneekluth & Bertram ch.2 系数关系）合成的**总体模型**，生成器即真相来源：
`Cwp ≈ (1+2Cb)/3`、`Cm ≈ 1-0.20(1-Cb)^1.8` 加小幅散布，`seed=42` 可完全复算。

**参数表**（本轮重建设置）：

| 参数 | 取值 | 说明 |
|---|---|---|
| 船数 | 120 | 合成总体模型，seed=42 |
| 网格 | nx=81, nz=21 | 纵向站位 × 垂向层 |
| 体积容差（G6） | 3 % | 参数化离散允许误差 |
| 尺度容差（G7） | 2 % | L/B/T 一致性 |

| 三角面下限（G8） | 1000 | 非占位符 |

## ② 怎么做的（方法 / 流程 / 关键设置）

**新方法：系数标定族**（`tensorcad/cb_sections.py`）。不再"选一个固定宽度的母型、祈祷 Cb 撞上"，
而是直接由系数反解形状：

* 宽度律 `b(x) = B/2 · sin(πx/L)^s` —— 由 `Cwp` 定 `s`
* 丰满度律 `c(x) = Cm · sin(πx/L)^r` —— 由 `Cb` 定 `r`（`Cm` 在中横剖面自动成立）
* 剖面律 `y(x,z) = b(x) · ζ^p(x)`，`ζ = (z/T)^(1/2)` 的层分布 —— 逐站由局部剖面积定 `p`

关键点：**三个指数都是在网格真正积分的离散泛函数上二分求解的**，不是解析极限。
解析正确但 81×21 采样仍差 2–3 %——这正是第 2 轮 G6 挂掉的原因。标定后同一网格上
体积误差降到 6.45e-05（最大）、3.60e-06（平均）。

可行域：需要 `Cp = Cb/Cm ≤ Cwp`（水线面不可能比棱形系数更瘦），不满足则**明确拒绝**并在
`problems()` 中报出，而不是返回一个偷偷偏掉的网格。

**流程**：`build_shipd_database(500, seed=42)` -> `run_shipd_rebuild(method_preference=...)`
跑两条链（`legacy` = 第 2 轮 Series 60 / 参数化 / Wigley 链；`calibrated` = 新族），
每条船做 8 项原有质量门 + 2 项系数门（Cm/Cwp 实测 vs 请求），
再把网格实测的湿表面积/排水体积与**标称性能字段**对拍。

**标称性能字段**（`tensorcad/shipd_population.py`，全部为公开经验式）：
`S = L(2T+B)√Cm(0.453+0.4425Cb-0.2862Cm-0.003467B/T+0.3696Cwp)`（Holtrop & Mennen 1982，无球鼻），
`1+k1` 同文形状因子式，`Cf = 0.075/(log10Re-2)²`（ITTC-57），`Rt ≈ (1+k1)·0.5ρV²S·Cf`（仅粘性），
设计航速由各船型典型设计 Froude 数给出。这些字段不看网格，是几何必须能复现的**目标**。

工具链：纯标准库核心（`tensorcad` 不引入新依赖），图表用 matplotlib，重算经调度系统递交。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **端站必须精确置零**：`math.sin(math.pi) = 1.2e-16`，`(1.2e-16)**0.07 ≈ 0.077`。
   求解时用 sin^β、生成时用 0，会让求解与放样差出整个端面板，Cwp 出现 8e-5 的假误差。
   两处必须用同一套"端站置零"约定（本轮的 `sine_power_mean` 已对齐）。
2. **体积不是绝对机精度**：逐站剖面积是精确的（Cm 误差 ~1e-16），但纵向放样在站间是直纹面，
   面积沿 x 的变化是二次的，梯形积分与真实体积差 O(A''·dx²/12)。Cb 0.45 这类尖瘦船
   在 nx=41 时实测 Cb 误差 0.01 %，nx=81 时降到 ~3e-4。仍在 3 % 门内 15 倍以上，
   但不宣称"零误差"。
3. **族本身不是船型线图**：无平行中体、无球鼻、无方尾、无外飘、无水线凹折，LCB 被正弦律锁在 L/2。
   它是**系数忠实的**几何，适合网格质量 / 静水力自洽 / 求解器前处理，不适合直接拿去做阻力或耐波结论。
4. **湿表面积与 Holtrop 回归的 3 % 系统偏差**是族差异（无球鼻、无方尾、中体不平行），
   不是网格误差：体积/水线面是自洽的，面积是形状敏感的。渔船偏差最大（10.63 %），
   因为小 L/B 尖瘦船的回归区外推最远。
5. **合成总体模型不是 ShipD**：船型分布、系数关系是文献区间 + 课本近似式，不来自 MIT ShipD 的
   3 万船真实统计。若日后拿到 ShipD 原始偏移表，直接替换 `build_shipd_database` 即可，
   管线与闸门无需改动。
6. **重算走调度**：500×2 模式全量在本机被 guard 拦截，已改由计算调度系统（`run_compute`）执行，
   单核即可，约 24+27 s。

## ⑥ 误差判定（逐项 vs 基准，显式回答"是否 < 3%"）

| 关键量 | 基准 | 本轮实测 | 误差 | < 3 % ? |
|---|---|---|---|---|
| Cb（体积） | 参数向量 Cb·L·B·T | 最大 6.45e-05 | 相对 | **是**（4 个数量级余量） |
| Cm（最大站剖面） | 请求 Cm | 最大 4.74e-16 | 相对 | **是** |
| Cwp（水线面） | 请求 Cwp | 最大 1.89e-15 | 相对 | **是** |
| L/B/T | 请求主尺度 | 机精度（几何按尺度缩放） | 相对 | **是** |
| 湿表面积 | Holtrop & Mennen 1982 | 平均 3.20 %，最大 14.68 % | 相对 | 平均**是**、最大**否**（族差异，非网格误差；见 ⑤.4） |
| 排水体积 | Cb·L·B·T | 平均 0.00 % | 相对 | **是** |

**结论**：验收三项全部达成——
1. 120 船参数向量 -> 网格 -> 质量门统计：8 门 100.00 %，
   严格门（加 Cm/Cwp）100.00 %；
2. 与标称性能字段的相关性 sanity：湿表面积 R² = 0.99960、
   平均偏差 3.20 %、斜率 1.0225；
3. 失败模式分类账：`runs/shipd_rebuild_r3/calibrated/evidence.json` 的
   `failure_mode_ledger`（本轮为空账——没有失败船，这本身是可核对的结论），
   legacy 模式的失败账保留在同一目录供对照。

未达标 / 未做：湿表面积与 Holtrop 回归的**最大**偏差 14.68 %
超过 3 %，属于形状族差异（⑤.4），要让面积也对上必须引入球鼻/方尾/平行中体等真实船型要素——
那是下一个能力条目（见下）。
