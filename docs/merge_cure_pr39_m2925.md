# Cure report — PR #39 (`agent/m2925` → `main`)

Status: **conflict-resolved, tests green at or above the `main` baseline, pushed back to
`agent/m2925`**. Merge base `d75dd54` (PR #28); `main` at `311f45a`; branch tip before the
cure `ad86f4f`.

`main` had meanwhile shipped its *own* initial-stability block (`tensorcad/stability.py`,
`docs/stability{,/report.md,/results.json}`, `examples/stability/run_example.py`) from a
different mission, so PR #39 was not a textual conflict but a **duplicate-feature
conflict**: two implementations of `KM`/`GM` that had to be unioned rather than
overwritten. A mechanical `--theirs`/`--ours` overlay would have silently deleted one of
them; that is exactly what this cure avoids.

## How the union was decided

* `main`'s route: cut the surface with the waterline plane, chain the segments into loops,
  integrate area and second moments by Green's theorem (`waterplane_moments`).
* m2925's route: take the waterplane moments from the **flux identity** over the closed
  wetted surface (new `Hydrostatics.transverse_waterplane_inertia` /
  `longitudinal_waterplane_inertia` / `keel_z`), plus the closed-form analytic reference
  (`I_T` gamma identity, `I_L` tanh-sinh) and the `initial_stability(hydrostatics, …)`
  entry point.

Both are kept. In code they are one module with two entry points and two record
vocabularies; in documentation they are two routes with the same reference. Nothing from
either side was dropped: every m2925 API name still exists, every `main` API keeps its
behaviour, and both test suites run unchanged.

## Residual risk / what this cure does not do

* `WaterplaneMoments.transverse_centre_flotation` is `nan` on the hydrostatics route: the
  flux identity yields the moments, not `y_c`. It is reported as missing, not as zero.
* `docs/stability/report.md` and `results.json` are `main`'s run; m2925's run is a second
  pair of files rather than one merged table, because the two ladders are produced by two
  different entry points and hand-merging them would have made the JSON not reproducible
  by any single command.
* No large-angle `GZ`, free-surface correction, damage stability or class rule was added by
  either side, so nothing was lost there.
