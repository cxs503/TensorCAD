# Mesh-quality bridge: the canonical library wired into the production gate

> Generated by `tools/meshquality_bridge_bench.py` from `artifacts/meshquality_bridge/results.json`; every number below is injected. Figure: `artifacts/meshquality_bridge/plot.png`.

## 1. Case: which problem, on which meshes

`tensorcad.meshquality` (Verdict/Gmsh definitions, six cell kinds) was an island: the production gate `tensorcad.gate` computed its own facet aspect in its own loop, in its own dialect, and nothing in the pipeline could call the library. The four dialects this tree computes are all called "aspect ratio" and differ by constant factors, so a threshold copied from one to another silently changes meaning.

| mesh | points | facets | source |
|---|---:|---:|---|
| `box_unit` | 8 | 12 | unit cube, quads fanned to triangles (`Mesh`) |
| `box_stretched` | 8 | 12 | the same cube scaled 4x in x, so shape and anisotropy separate |
| `hull_41x13` | 1001 | 1998 | `hull.build_mesh(HullParameters(10, 2, 0.8, 41x13))` |
| `hull_81x25` | 3921 | 7838 | the same hull refined 2x in both directions |
| `hull_blunt` | 1001 | 1998 | `HullParameters(10, 3.2, 1.1, 41x13)`: beamier, so the stem facets are harsher |

## 2. Method: the bridge, and how it is checked

`tensorcad.meshquality.bridge.qualify(mesh)` converts any object with `.vertices`/`.faces` into (i) every canonical per-facet metric from the library's own `tri_metrics`, (ii) the four aspect dialects with their per-face transfer factors, (iii) the surface topology block, and (iv) the index+centroid of the worst facet for each gated metric. `tensorcad.gate.measure_gated` now records a `canonical` block, and `gate_mesh` accepts `max_canonical_aspect`, `min_canonical_angle`, `min_canonical_sicn`, `max_canonical_skewness`; `canonical_limits_from_legacy` derives the canonical limit from a legacy one using the proved bound `verdict >= legacy/2` composed with the exact identity `gate = 2 * legacy`.

Checks that can fail (all recomputed here, exit 1 if any breaks):

* `bridge gate dialect == gate._facet_aspect` on every mesh;
* `gate = 2*legacy`, `edge_form = legacy*alpha`, `verdict = legacy*alpha*beta` to rounding;
* `bridge min_sicn == meshquality.report.measure(...).summary()['tri']['min_sicn']`;
* `gate.measure_gated(...)['canonical'] == bridge scalars`;
* the red-team separation below.

### 3.3 Red team: why the limit is translated, not copied

A right isosceles triangle (Verdict's least favourable shape for the transfer):

* gate dialect 4.000000, verdict dialect 1.207107, ratio 0.301777;
* take a gate-dialect limit of 3.960000: the triangle violates it;
* a naive copy (`max_canonical_aspect = 3.9600`) **passes** it: True;
* the translated limit 0.9900 **rejects** it: True.

## 5. Caveats, and what is not claimed

* **External oracle still not run.** No `gmsh`, no `vtk`, no `meshmagick` on this loongarch64 host (the index in use carries no wheel), so the Verdict/Gmsh correspondence rests on the transcription plus the closed-form and dialect identities above -- not on a binary diff. This is the residual debt of the anchor, and it is a platform limit, not a choice.

* The bridge converts triangles only (the repository's `Mesh` cannot hold anything else); a quad face raises instead of being silently fanned.

* `min_canonical_angle = 10` deg is policy. The hull at 41x13 has a 7.13 deg facet at the stem (centroid in the artifact), so the wired gate fails it -- the numbers are measured, the threshold is a choice, and the document keeps them separate.

* A zero-area facet has `inf` in every aspect dialect and is counted (`non_positive_area`) rather than dropped; an inverted facet has a negative SICN/scaled Jacobian.
