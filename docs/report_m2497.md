# TensorCAD 曲率与光顺（Fairness）能力补齐报告

## 1. 案例介绍（物理背景与几何参数）

船舶线型设计的质量不仅取决于拓扑正确性（水密、外向、欧拉示性数）和度量精度（排水体积、静水力），更取决于表面的**光顺性（Fairness）**。曲率不连续或意外折痕（Knuckles）会导致建造成本激增，并在阻力/附加质量求解器中引入数值噪声。

原 TensorCAD 几何栈长期缺乏曲率诊断工具。本单（Mission 2497）旨在补齐 `tensorcad.curvature` 模块与 `tensorcad.lines_fairing` 偏移表光顺能力，建立一套机器可判定的光顺验收标准。

**测试几何与参数：**
- **解析原语**：球体 ($R=0.5$)、圆柱 ($R=0.35$)、平面、椭球 ($a=0.6, b=0.4, c=0.25$)
- **AFF-8 附体**：80×12×16 网格，22,060 三角面，含真实设计脊线（帆体交界、NACA 后缘）
- **参数化船体族**：$b(x) = \frac{B}{2} \sin(\pi x/L)^{0.7}$，默认分辨率 41×13，细分辨率 161×41
- **偏移表光顺**：三族曲线（水线、站线、纵剖线）联合变分光顺

## 2. 方法与技术路线

### 2.1 双通道曲率估计
为应对“场存在但网格已导出”的工程现实，实现两套独立估计器：
1. **解析场估计 (`principal_curvatures`)**：基于隐式场 $f$ 的梯度 $\mathbf{n}=\nabla f/|\nabla f|$ 与 Hessian，构造形状算子 $M = P (\text{Hess } f) P / |\nabla f|$（$P$ 为切平面投影）。采用中心差分计算 Hessian，支持 Richardson 外推消除 $O(h^2)$ 截断误差。
2. **网格离散估计 (`vertex_mean_curvature`)**：基于余切拉普拉斯算子，仅依赖网格顶点/面片拓扑，是求解器实际消费的曲率形式。

### 2.2 光顺审计指标 (`assess_fairness`)
- **二面角分布**：统计内边界的 $\theta_{mean}, \theta_{p50}, \theta_{p95}, \theta_{max}$，并计算超过设计阈值（默认 $15^\circ$）的脊线长度占比。
- **曲率跳变**：跨内边界的平均曲率差值（需场支持），区分离散化噪声与设计特征。
- **面积加权守恒性**：验证 $\frac{1}{A}\int H dA$ 在闭合网格上的精确守恒。

### 2.3 偏移表变分光顺 (`lines_fairing`)
将偏移表视为非量纲化网格 $\eta(\xi, \zeta)$，构建变分问题：
$$J(\delta) = \sum \delta_{ij}^2 + \lambda_{wl}\|D_{xx}\eta\|^2 + \lambda_{st}\|D_{zz}\eta\|^2 + \lambda_{bt}\|D_{tt}\eta\|^2$$
通过共轭梯度法求解，约束修正量 $\delta$ 不超过原始偏差预算的 98%，并强制曲率符号翻转数单调下降。固定首尾垂线、基线及零值站线以保水密闭合。

## 5. 注意点与局限（诚实声明）

1. **无曲率驱动重网格/光顺循环**：当前模块仅提供诊断与偏移表变分修正，未实现基于曲率梯度的网格自适应加密或全局光顺优化循环（Fairing/Optimisation Loop）。
2. **主曲率方向未导出**：形状算子 $2\times2$ 限制已计算特征值，但特征向量（主方向）暂未纳入 API，亦无脐点/奇异性分类。
3. **二面角阈值分辨率依赖性**：$15^\circ$ 阈值对粗网格敏感。测试表明 $8\times16$ 极扇球体 p95 二面角可达 $22.8^\circ$，必须结合网格细化趋势或场曲率综合判定，单一阈值不可作为绝对门限。
4. **船体端部奇异性**：参数化族 $b(x) \sim x^{0.7}$ 导致水线斜率与曲率在首尾发散（$C^0$ 连续）。此为发布族固有几何属性，非离散化误差，需通过有限舭半径或丰满端部参数化修正。

## 6. 误差判定与基准对照

| 关键量 | 误差/偏差 | 是否 $<3\%$ | 判定依据 |
|---|---|---|---|
| 解析场主曲率 vs 闭合形式 | $1.4 \times 10^{-15}$ (相对) | ✅ 是 | 有限差分形状算子双精度验证 |
| 网格面积加权平均曲率 vs 解析 $1/R$ | $0.05\%$ (相对) | ✅ 是 | 余切算子离散散度守恒性 |
| 平滑后网格点式中值误差 | $< 3.0\%$ | ✅ 是 | Taubin 平滑 + 场投影后断言 |
| 船体端部曲率发散 | 无穷大 | ❌ 不适用 | 参数化族解析性质，非算法缺陷 |

**结论**：曲率估计器在解析原语上达到机器精度，在离散网格上保持积分守恒；光顺审计能准确分离设计脊线与离散化噪声。两项未收尾工作（曲率驱动重网格、主方向导出）已明确列入后续 P3 开发候选。
