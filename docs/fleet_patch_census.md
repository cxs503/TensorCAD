## Reading

* **trim bound / #144** is the binding `tensorcad.iges` has to resolve before a trimmed patch means anything. Before the fix behind this census the count was `0` on every hull that ships type-144 wrappers, because the outer boundary was read out of parameter 4 and the curve-on-surface basis surface out of parameter 2 — both off by one field. A mis-bound patch is silently treated as its whole basis surface, which inflates `max|y|` in the half-breadth field and — on a file whose patches are mostly untrimmed overhang — moves the volume.
* **degenerate** counts patches whose basis surface evaluates to the model origin at every sample inside its own trim loop. Those patches contribute nothing to a reconstruction, so a volume built from this file is a *partial* hull, and any verdict on it must say so.
* The census is deliberately blind to the reference volume: it reports reader coverage, not accuracy. A hull can have every patch bound and still be `WITHHELD` for a frame reason.
