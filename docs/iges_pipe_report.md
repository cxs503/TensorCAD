# GAP-CAD-T1-IGES-PIPE 进展报告

## 案例介绍

工业标准 CAD 格式（IGES 5.3 / STEP AP203/214）到水密三角网格的转换是船舶 CFD/结构分析的前置刚需。出版商（Tokyo 2015 / SIMMAN 2020 研讨会）发布的船型几何以 IGES B-spline 曲面形式提供，但这些文件包含数十个独立补丁，补丁间边界不共享顶点，直接三角化会产生裂缝和非水密网格。

本管道解决的核心问题：
- **KCS**: 55 个 B-spline 补丁，Lpp=230m
- **KVLCC2**: 38 个 B-spline 补丁，Lpp=320m  
- **ONRT**: 完整船体 IGES
- **金标**: DTMB5415_Hull_exact.stl（164,926 三角形）

## 方法/流程

```
IGES 文件 → 解析(iges.py) → 反演(trim_mesh.py) → 三角剖分 → 网格修复 → 门控验证 → Mesh+Report
```

关键算法：
1. **B-spline 求值**: de Boor 算法（有理形式），零依赖
2. **曲面反演**: Gauss-Newton + Levenberg 阻尼，网格种子 + 精细回退
3. **三角剖分**: 耳切法 + 奇异边重建 + 内部采样加密
4. **网格修复**: 焊接 → 退化面删除 → 重复面删除 → 孔填充 → 重定向
5. **门控验证**: 7 项检查（G1-G7）

## 注意点

1. **多补丁缝合限制**: KCS/KVLCC2 的补丁边界顶点不完全对齐，当前焊接公差（1e-3 m）不足以闭合所有缝隙。需要更精细的边界投影策略或 OCP 桥接。
2. **OCP 不可用**: LoongArch 平台无 pythonocc-core 预编译轮，STEP 写入功能不可用。
3. **meshmagick 未安装**: 网格简化和高级修复功能不可用。
4. **性能**: 高补丁数文件（>50 补丁）的反演步骤可能需要数分钟。
