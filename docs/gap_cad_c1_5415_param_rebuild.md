## 1. 案例介绍

### 物理背景与数据来源

DTMB 5415 是船舶流体力学标准船型，本模块从 Zenodo 发布的 **9001 构型 × 27 设计变量** 基准数据集中重建参数化模型。数据集由 Serani, Palma, Wackers, Quagliarella, Gaggero, Diez 等人发布（Engineering with Computers, 2025），每构型含 2250 个表面点及生成该构型的 27 个归一化设计变量。

| 几何尺度 | 全尺度, Lpp = 142 m | 数据集 README |
| 模型尺度 Lpp | 5.720 m | 数据集 README 表 |

| 源文件 SHA256 | `16b14ba5...` | 1.087 GB .mat 文件 |

### 重建方法

设计空间重建采用 **PCA 模态位移场 + 二次特征提升**：

```
d(v) = Φ · (C₂ · [v, vech(vvᵀ)])
P(v) = P_ref + d(v)
```

- `Φ` (6750 × 40): 位移 PCA 基，捕获 97.84% 方差
- `C₂` (40 × 405): 最小二乘系数矩阵（含线性块）
- 特征向量: 27 个线性项 + 378 个二次项 = 405 维

**网格生成**: 双三次样条插值 → 49×133 细化 → 关于 y=0 镜像 → 缝合

**对称面修复**: 数据恢复的代理模型在艉部会穿越对称面（最大 -0.30 m），采用 Euclidean 投影 `y = max(y_raw, 0)` 修复，保证几何合法性。

## 6. 注意点与局限

### 已修复的缺陷
- **Round 0 线性块重复计数**: C₂ 已包含线性列，额外加 C₁v 导致保持集 RMS 从 0.252 m 恶化至 0.833 m，14/20 配置失败几何门。已修复。
- **Round 0 单位混淆**: 将全尺度排水体积 (8240 m³) 与模型尺度吨位 (8.412) 比较，并将 Cb 除以 1000。已修复。
- **Round 0 循环验证**: 水线被调谐以复现目标排水量，然后用该排水量"验证"水线。已修复为独立测量。

### 诚实缺口
1. **水线裁剪不可微**: 水线裁剪的导数在截面穿越水线时跳跃，`hydrostatics()` 不提供梯度。这是物理事实，不是 bug。
2. **对称面投影分段仿射**: Jacobian 携带 0/1 掩码，在活跃集切换的零测集上不光滑。`half_breadth_clamped_fraction` 报告受影响顶点比例。
3. **代理模型误差**: 保持集 RMS ~0.25 m（2.45% Beam），最坏配置最大误差 ~4.6 m。这是数据恢复代理的固有限制。

### 适用范围
- 设计变量在 [-1, 1] 范围内（训练域）
- 外推至 [-1.2, 1.2] 仍可通过几何门（均匀样本测试）
- 不适用于超出训练域的极端设计
