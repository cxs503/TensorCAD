# GAP-CAD-C1-5415-PARAM-REBUILD — Zenodo 9001×27 参数化 DTMB 5415 可微重建

## ① 案例介绍
DTMB 5415 标模。数据源 = Zenodo《Design-Space Dimensionality Reduction Benchmark Dataset – DTMB 5415 Hull》(Serani, Palma, Wackers, Quagliarella, Gaggero, Diez)：**9001 配置 × 27 归一化设计变量**，每配置 **2250 全尺度曲面点**（Lpp=142 m，6750 几何 DOF）。
本地源 `DTMB5415-database.mat`，1086721690 B，**sha256=16b14ba598787eeed74eb6a10e9ea6fb701bd25496b5ccbf8a317ad6e364bee2**；第 0 列=基准 5415，与平台 `DTMB5415_Hull_exact.stl`（sha256 `d40b17b1fc963e0d…`，164926 面）包围盒逐位一致。
开工三查：knowledge_base `TensorCAD`/`parametric hull` → **0 条**；negative_knowledge_ledger `TensorCAD` → **0 条**；oss_solutions 同域存储为空 → **无既有先验可借**。

## ② 怎么做的
1. **布局反演**：2250 点非散点，是 `2 patch × 25 girth × 45 station`（index=45·(2j+patch)+i；艏段 x∈[81.79,151.80]，艉段 x∈[-0.10,80.13]）。由基准列实测，并在 `point_grid()` 内用不变量（站内 x 展布<5%L、girth 舷缘→中线）硬校验。
2. **设计变量→位移场**：`d(v)=Φ·(C1 v + C2(v⊗v))`，Φ=位移场前 40 PCA 模态（fit 集），C1/C2 为 27 变量与 378 二次项最小二乘；v=0 精确回基准型。划分预置：配置号 `%5==0` 留出（1801），其余 7200 拟合。
3. **位移场→mesh**：`(girth,station)` 指标空间自然三次样条双三次细化 49×133/面片，镜像整船+跨面片缝缝合；细化/镜像是固定线性算子 → `vertices(v)` 对 v 仿射。
4. 数字全部程序化生成（零手抄），复现：`PYTHONPATH=. python3 tools/dtmb5415_param/fit_design_space.py` → `PYTHONPATH=. python3 tools/dtmb5415_param/run_acceptance.py`（32.9 s）。

## ⑤ 注意点 / 局限
* 数据布局未文档化：2250 点扁平顺序需实测反演（艏艉交错），重排会让缝合错位——已加不变量硬校验。
* 面片缝（x≈81 m）两侧站位不重合（82.35/80.11），用桥接带缝合；舷缘开口无甲板面 → 开壳，体积按「中线闭合到舷缘」定义（**不是水线下排水量**，后者单列）。
* 自写样条算子首版漏 6×二阶差分右端项（把 y 当 M 用），表现为网格外溢到 x=197 m、最长边 45 m；已修并加「节点处算子=单位阵」校验。
* 数据集不发布参数化本体：27→几何只能回归重建，留出残差 2.45%B 属**模型形式误差**而非测量误差，也是抽样门失败的主因（远离基准的形变下最小角/长宽比退化）。
* 站位 x 单调性作为设计域边界检查，越界抛错而非静默积错。
