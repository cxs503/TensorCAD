# Golden case 5: the attitude module (combined heel + trim)

锚点 `GAP-CAD-D2-GOLDEN-REGRESSION`（几何金标回归套件+CI）的覆盖补全，单号 m22879。

## 缺口

原四个金标 case（Wigley / Series 60 / 球椭球 SDF / DTMB 5415）**全部在正浮无纵倾**姿态下测量。
`tensorcad/box_inclined.py`（盒体受平面切割的精确静水力：体积、浮心、水线面面积/惯性矩）
是这套库里唯一处理**同时横倾+纵倾**的几何路径，它的自测只覆盖单轴极限（纯横倾 vs 二维剖面、
纯纵倾 vs 平面切割力矩），组合姿态下没有任何独立基准。因此对姿态约定（水线法向符号、
剪切面、水线面面积的面上因子 1/n_z）的改动，四个金标 case 一个都不会动 —— 门禁是瞎的。

## 本次增量

1. `tools/golden/inclined_box_oracle.py`：与库**结构不同**的独立基准——按列积分
   （每列 `0 ≤ z ≤ z_w(x,y)` 在 z 向解析积分，x/y 向复合 Simpson 1200 区间），
   不建面、不做面剪切、不做三角面力矩求和；水线偏置由二分按"位移量守恒"解出。
   自证：正浮极限回到教科书闭式（V=L·B·T、VCB=T/2、A_wp=L·B），并给出自身二阶收敛表。
2. `tensorcad/golden_inclined_box.py`：第五个金标 case `inclined_box`
   （L=10, B=4, 深 3, V=L·B·T=60 m³, 横倾 15°, 纵倾 3°），三量测六指标
   （∇、LCB、TCB、VCB、水线面面积、水线偏置）+ 两条零外部基准恒等式
   （∇ 必须等于请求排水量；横倾取负必须镜像横流浮心）+ 切割实体的指纹。
3. `tests/test_golden_inclined_box.py`：8 项测试（极限闭式、二阶收敛、三组组合姿态对拍、
   0.2 % 扰动检出、注册与指纹锁）。
4. CI 与回归测试的 case 集合断言加入 `inclined_box`。

## 误差判定

六项关键量 vs 独立基准全部 **≤ 2.6e-13**，远小于 3 %；验收带取门禁的 1e-4 复现地板
（两条路线都是精确解，没有离散化信号可推容差，门禁在 basis 里如实记录这一点）。
所以这不是收敛性 case，是**建模锁**：几何/约定回退 >1e-4 即判 FAIL，收敛性仍由三个网格 case 承担。

## 注意点

- 本 case 只有单一 level（`exact`），验收带即 1e-4 地板；门禁报告里写明理由。
- 基准在 `tools/` 下、由路径加载：`tensorcad` 不得对工具目录产生 import 依赖；
  改动被判的库无法同时移动基准。
- 该 case 的检出下界实测：水线面面积注入 0.2 % 偏移必被判 FAIL（测试内验证），
  而其余指标不动（定位到具体指标）。
