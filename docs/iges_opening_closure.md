# 边界开口分类与平面切割封盖（GAP-CAD-T1-IGES-PIPE）

**锚点** GAP-CAD-T1-IGES-PIPE · 模块 `tensorcad/geomquality/openings.py` · 管道阶段 `trim_mesh.seal_stage`
**日期** 2026-11-16 · 分支 `agent/m22645`

## 1. 问题

进口管道对真实出版方 IGES（水密门 G1–G7）的最后一道缺口是 **开口边界**。此前记录只说
「自由边 N 条、未水密」，但同一个自由边计数混着两种几何性质完全相反的东西：

- **平面切割**：CAD 系统在某个平面切过（半船对称面、艉封板、艏剖面）。开口是**信息**不是损伤，
  用该平面封盖不臆造任何曲面，包围体积随之良定义。
- **缺陷缝**：相邻面片重叠或错位，边界在船体表面上乱走。没有任何方法能从这里恢复几何。

此前没有任何代码把这两者分开，于是「3 个真实 IGES 全过门」无法判定：既能被读成「管道差」，
也能被读成「输入不完整」。本单把判定做成可复算的量。

## 2. 方法

1. `boundary_loops()`：把 count==1 的自由边按面片绕向串成环（确定性：索引顺序，无 set 迭代序依赖）。
2. `classify_openings()`：对每个环做最小二乘平面拟合（3×3 协方差最小特征向量；幂迭代 M = tr(C)·I − C，
   四个起始向量取残差最小者，避免正交失速），记录 **planarity residual**（顶点到拟合平面最大距离）、
   周长、最长边、法向；`residual ≤ tolerance` → `planar_cut`，否则 `defect_gap`。
   默认容差 = 1e-3 × 模型最大尺度（同一相对标准判米级船与毫米级模型）。
3. `seal_planar_openings()`：**只封 `planar_cut`**。环投影到自身平面基 → ear clipping（凸性用多边形自身
   有向面积定号，卡住返回 None 而不是错的三角化）→ 追加三角形，**复用环的既有顶点、绕向取反**
   （一致定向曲面的自由边方向不能重复使用）。缺陷缝原样留开并如实报告。
4. 管道接入：`import_iges` / `import_patch_set` / `import_cad` 新增 `seal_openings`（默认 False=只测量）、
   `seal_planarity`、`opening_audit`；`report["openings"]` 给出 before/after/封盖记录；CLI 新增
   `--seal-openings` / `--seal-planarity`。七门自动反映封盖后的网格 —— 门自己不会因此变绿。

### 3.2 真实出版方 IGES：KCS_hull_SVA.igs（55 patch，246 164 B）

封盖前（镶嵌 + 焊接后、修复前）：自由边 **1697** 条，分 55 环，判定
**`mixed_planar_cuts_and_defect_gaps`**；其中平面切割边 **765** 条（25 环），缺陷缝边
**932** 条（30 环）。容差 0.244 m。

**诚实的关键点：真实文件里两类并不按数量级分离。** 平面切割环的最大残差
0.22 m，缺陷缝环的最小残差
0.37 m，而容差是 0.244 m ——
即最"平"的缺陷缝只比容差大 1.5 倍，分类在容差附近是**边缘判定**，不是干净的两类。

## 5. 注意点 / 局限

- **封盖只对平面切割合法**。对近平面但实际弯曲的环（如艉部大半径圆弧），容差放宽会错误封盖；
  默认 1e-3×尺度是按 KCS 实测分离度定的，调用方可显式传 `seal_planarity`。
- ear clipping 在自交/共线环上返回 None 并跳过（记录 `capped=False`），不会产生错三角化。
- 缺陷缝无法通过任何「标准库缝合」闭合：这是输入性质（前序实测：缝偏移中位数 7.4 mm、90 分位 0.76 m，
  面片互相重叠而非对接）。要闭合需 OCP 愈合或 CAD 侧重新导出缝合 B-rep。
- KVLCC2 / ONRT 的全门矩阵需在计算节点跑（本机 120 s 硬限，单文件导入 >120 s）：作业 **cj4277**
  （`tools/iges_pipe/closure_matrix.py`）。截至本报告发布，该作业仍在排队 —— 记为 **not_run**，
  不写成通过。
