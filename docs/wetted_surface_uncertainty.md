# 湿表面积闭包误差的不确定度（误差棒 + 网格收敛 / GCI）

> 本文件由 `tools/wetted_uncertainty_doc.py` 从 summary.json 程序化生成，零手抄。

## 1. 缺口与要回答的问题

课题 `wetted-surface-geometry` 的 W10 事实项 `gaps` 标记「缺不确定度/误差棒/GCI」。报告 #3871 已给出湿面积闭包误差到总阻力的解析传播（dRt/Rt = pi * dS/S），但闭包误差本身没有棒：读者无法判断这个偏差是网格不够细，还是模型本身偏。本文补三样东西：

1. **数值不确定度** u_num：同一被积函数用三种不同求积规则 + 网格收敛序列 + Richardson/GCI；
2. **输入参数不确定度** u_in：解析灵敏度 dlnS/dlnX 与量测容差经 GUM 一阶 RSS 合成 95% 区间；
3. **偏置与不确定度分开报**：偏置不能用对称小棒掩盖。

## 2. 几何与参数（先验校验 Cb/L/B）

基准几何取 `tensorcad.hull` 的解析族 y = (B/2) sin^p(pi x/L) sqrt(zeta)（zeta 自龙骨量起）：Cm = 2/3、Cwp = int_0^1 sin^p(pi x) dx、Cb = (2/3) Cwp 全部闭式可算，所以闭包误差是可测的量，不是断言。

| 量 | 值 | 来源 |
|---|---|---|
| L / B / T | 100 / 16 / 6 m | summary.design |
| 纵向正弦指数 p（首尾同值） | 0.7 | summary.design |
| Cb | 0.469544 | 闭式 (2/3) int sin^p |
| Cwp | 0.704315 | 闭式 int sin^p |
| Cm | 0.666667 | 闭式 |
| 排水体积 LBT*Cb | 4507.619 m3 | 解析 |
| 网格积分体积（321 x 161） | 4506.706 m3 | `compute_hydrostatics` |
| 网格 Cb 相对偏差 | -0.0203% | 体积一致性 <0.1% 通过 |

## 3. 方法

### 3.1 三条独立求积规则（同一被积函数）

在 (x, u)、zeta = u^2 图上面元为 sqrt(4 u^2 T^2 (1 + (beta_x u)^2) + beta^2)，beta = (B/2) sin^p(pi x/L)；u 代换把龙骨处 zeta^-1/2 的斜率奇异吸进 Jacobi 因子。三条路径只差求积规则：

- **A（仓内）**：`tensorcad.hull.analytic_wetted_surface_area`，Gauss-Legendre + psi ~ tau^3 节点聚拢，节点 80/160/320/640；
- **B（双指数）**：`tensorcad.hydrostatics_analytic.analytic_hydrostatics(quadrature_levels=4..8)`，嵌套 tanh-sinh，自带自收敛差；
- **C（仲裁）**：本文自写嵌套自适应 `scipy.integrate.quad`（Gauss-Kronrod），自适应分裂自行找到首尾 x^-0.3 边缘。

### 3.2 网格收敛与 GCI

把解析面采样成三角网格（nx x nz = 41x21 -> 321x161，面元尺寸每次减半），用 `compute_hydrostatics` 对网格本身积分湿面积，与解析参考值之差即可验证真误差 e(h)。于是：

p = -log2|e(2h)/e(h)|；Richardson f_ex = f_fine + (f_fine - f_med)/(r^p - 1)；Roache GCI（Fs = 1.25，取作 ~95% 带）= Fs |f_med - f_fine| / (|f_fine| |r^p - 1|)。

### 3.3 输入参数不确定度（GUM 一阶 RSS）

闭包误差 e = Sp/Se - 1，故 de/dlnX = dlnSp/dlnX - dlnSe/dlnX 由中心差分数值给出。量测容差是显式假设（非实测），见 §6。

## 6. 注意点 / 局限

1. **输入容差是假设**：半宽 ±0.5% B、吃水 0.02 m、L ±0.05 m、Cb 0.2% Cb。换一套容差得同形预算的 rho 倍；偏置/不确定度之比仍约 78 倍。
2. **本几何不是实船**：Cm = 2/3、Cwp = Cb 是解析族的固定组合，而闭包假设 Cwp = 0.75 + 0.25 Cb；结构误差与闭包误差反号部分抵消，总偏置是净值，不能读成某艘船的误差。
3. **GCI 适用面**：p 约 1.2 是面积积分对网格的观测阶；位移体积走散度定理，收敛阶不同，不可挪用。
4. **pi 的来源**：pi 由平台阻力回归给出，其自身误差不在本文预算内；本文只传播湿面积一支。
5. 平台响应只回 2 位小数，故对拍判据定在 1e-5 ~ 1e-6，而非机器精度。
7. **第三方求积只在本几何适用**：`tensorcad.hydrostatics_analytic` 保留自己的默认 taper，对 p≠0.7 它积的是另一条船（Cwp 不符），故 path B 只在 p = 0.7 计入预算；族扫描中 p ∈ [0.35, 0.45, 0.55, 0.9, 1.1] 的 U95 由 path A 的网格 GCI 与自适应仲裁给出。这条是本轮修正的：此前那些点的 nan/0 值让跨积分器互校假通过。

6. **传播结论有速度窗**：3% 带只在 Fn >= 0.13 成立；低速端 pi 上升而 dS/S 不变，传播误差单调上升，最低速点越界。
