# Mesh quality: one library, measured against something that is not itself

> Generated by `tools/mesh_quality_doc.py` from `artifacts/mesh_quality/results.json`
> (sha256 in `artifacts/mesh_quality/manifest.json`); every number below is injected
> from that artifact. Figure: `artifacts/mesh_quality/plot.png`.

## 1. The gap this closes

Three modules measured mesh quality before this one, each in its own vocabulary:
`tensorcad.validation.inspect_mesh_quality` (minimum angle, aspect ratio, sliver share;
triangles only), `tensorcad.volume_mesh.VolumeMesh.quality` (scaled Jacobian; hexahedra
and the Kuhn tetrahedra) and `tensorcad.geomquality.mesh_defects` (facet defect codes).
None of them named a reference, so none of them could be checked against Gmsh or VTK, and
a solver asking "is this mesh usable?" had to know which of the three to ask.

`tensorcad.meshquality` is the library behind that question: four cell kinds, an explicit
normalisation for every metric, outlier-resistant statistics, a threshold gate that returns
data, a JSON exchange format and a CLI whose exit status is the CI contract.

## 2. Method, definitions and provenance

| family | metrics | definition and source |
|---|---|---|
| shape only | `scaled_jacobian`, `min_angle`, `max_angle`, `edge_ratio`, `aspect_ratio` | Verdict / `vtkMeshQuality`, the metrics `meshmagick.print_quality()` reports (meshmagick delegates to VTK). `scaled_jacobian` divides the element Jacobian by its column norms: 1 for a cube, square or equilateral triangle, `1/sqrt(2)` for a regular tetrahedron. |
| shape + anisotropy | `min_sicn` | `d |det J|^(2/d) / ||J||_F^2` at the element corners, normalised to the **ideal** element of that type (equilateral triangle, square, regular tetrahedron, cube), signed so an inverted cell is negative. Same expression as Gmsh's `qualityMeasuresJacobian.cpp`. |
| Gmsh units | `gamma`, `eta`, `gmsh_icn` | transposed from Gmsh `src/mesh/qualityMeasures.cpp` (blob `dcc7972`): `gamma` = 2r/R for triangles and 3r/R for tetrahedra, `eta` = (1 - |60-a|/60) for triangles, 12(3V)^(2/3)/sum l^2 for tetrahedra, 1 - max|90-a|/90 for quadrilaterals, `gmsh_icn` = Gmsh's `minSICN` in Gmsh's reference-tetrahedron unit (regular tetrahedron = 0.7937). |
| geometry | `area`, `volume`, `min_edge`, `max_edge`, `min/max_dihedral` | direct measurement; volume by the divergence theorem over the six faces (warped hexahedra included). |

The two conventions that cause most arguments are stated in the module docstring and
tested: an anisotropic but orthogonal cell scores 1.0 in `scaled_jacobian` and below 1 in
`min_sicn` (the stretched box below shows both), and Gmsh's `minSICN` unit differs from the
ideal-shape one only for tetrahedra, by the reference element (`gmsh_icn` is the column to
compare against Gmsh).

### 4.5 The gate must discriminate

* canonical and box meshes pass: `ideal_tri`, `ideal_quad`, `ideal_tet`, `ideal_hex`, `box_ideal_hex`, `box_stretched_hex`;
* a sliver triangle fails `tri.min_sicn`, `tri.scaled_jacobian`, `tri.min_angle` (its `min_sicn` is 0.00023094)
  and the CLI exits 1 on it;
* `hull_hex` fails the default gate at `min_sicn = 0` because the structured hull grid
  contains collapsed keel/stem columns (zero-volume cells); `VolumeMesh.quality()` excludes
  them silently, this gate counts them. The `positive_only` block in the artifact reports
  the same statistics with zero-measure cells removed, so the choice is visible rather than
  hidden. `hull_surface_tri` fails the 10 deg angle policy at the stem (7.13 deg) and
  `hull_tet` the 0.1 `min_sicn` policy (0.042 on positive cells): the thresholds are policy,
  the numbers are not.

## 5. Not run, and why

* **gmsh**: not installed: the gmsh wheel is published for x86_64/aarch64 only and this host is loongarch64 (pip download gmsh -> 'no matching distribution'). Run `python -c "from tensorcad.meshquality.reference import gmsh_element_qualities as g"` on a host with gmsh to compare gmsh_icn against getElementQualities('minSICN').
* **meshmagick**: not on the package index and GPL-3.0; its print_quality() delegates to vtk.vtkMeshQuality, whose Verdict definitions the metric module mirrors. A VTK wheel for loongarch64 does not exist, so the runtime comparison cannot run here.

## 6. Reproduction

```
python examples/mesh_quality/run_benchmark.py
python -m tensorcad.meshquality.cli --input artifacts/mesh_quality/hull_surface_tri.json \
       --json /tmp/hull_quality.json
python -m pytest tests/test_meshquality.py -q
```

Failure modes the library refuses to hide: inverted cells are negative (not zero), a
collapsed cell has zero measure and is counted as non-positive by the gate, and an unknown
cell kind or an out-of-range index raises instead of being skipped.
