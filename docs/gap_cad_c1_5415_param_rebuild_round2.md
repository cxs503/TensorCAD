# GAP-CAD-C1-5415-PARAM-REBUILD · round 2：对称面可行性修复（判据 2 由 19/20 → 20/20）

**锚点**: `GAP-CAD-C1-5415-PARAM-REBUILD`（Zenodo 9001×27 参数化 5415 可微重建）
**验收原文**: 配置 0 与 DTMB5415_Hull_exact 逐点对照（>95% 点距<网格分辨率）；抽样 20 配置过几何质量门；梯度链路若断如实报
**上一轮（round 1, m17472）结论**: 判据 1 PASS、判据 3 PASS、**判据 2 = 19/20 如实 FAIL**（配置 4895 `half_breadth_non_negative`）
**本轮**: 把该 FAIL 变成构造性 PASS，并如实交代「修的是几何有效性，不是模型精度」

---

## ① 案例介绍（物理背景 / 几何 / 参数）

DTMB 5415 是船舶水动力学标模。Zenodo 设计空间数据集（Serani et al. 2025）公布 **9001 个配置 × 27 个归一化设计变量**，每个配置给 2250 个船体表面点（2 patch × 25 girth × 45 station 结构网格，`index = 45(2j+patch)+i`），**不公布**参数化模型本身。TensorCAD 的重建是

```
P(v) = P_ref + Phi · (C2 [v, vech(v v^T)])        Phi: 6750×40 (位移 PCA), C2: 40×405
vertices(v) = L · P(v)   L = 固定样条细化算子（25×45 → 49×133 / patch，再镜像）
```

全尺度 Lpp=142 m（λ=142/5.720），B≈20.5 m，设计吃水 T=0.248λ=6.1566 m。

**缺陷（本轮修复对象）**：`y ≥ 0`（右舷半宽非负）是船体的**硬几何约束**。数据回归出的位移场不保它——在艉部近中线处，代理模型把 `y` 尾巴过冲到负值。mirror 之后左右舷互相穿透，网格在对称面处自我折叠，几何无效。

## ② 怎么做的（方法 / 流程 / 工具链）

1. **定位**（只读诊断）：把 12 个 holdout 配置的 raw 细化网格取 `y` 最小值。结果：不是「-1e-6 量级的数值毛刺」，配置 4915 的 raw 最小半宽是 **-0.3022 m**、配置 4895 是 **-0.2309 m**；另有 3 个配置在 -0.009…-0.014 m。**round 1 报告里「-1e-6 量级之外」这句低估了越界量级，此处更正。**
2. **机理**：dataset 真实点云的中线行 `y` 位移 rms = 5.4e-12（真值是精确 0），PCA 基在中线行的 y 分量为 0（拟合自动满足）；所以越界**不是**中线行，而是**中线邻域的 girth 行**——真值 `y` 尾巴平缓（0.64, 0.50, 0.39, 0.30, 0.21, 0.12, 0），代理模型把它压得过快再回弹（1.87, 0.96, 0.25, **-0.17, -0.28, -0.20, -0.06**, 0.04, 0）。即**模型误差**（艉部近中线），不是样条振铃单独造成的（knot 级 clamp 后细化仍有 -0.10 m 残差）。
3. **修法**（`tensorcad/dtmb5415.py`，单点收口）：在网格管线的唯一汇聚点 `station_grid` 上做**欧氏投影**

   ```
   grid_feasible = max(grid_raw, 0)          # 只动违规点的违规坐标，最小范数修正
   ```

   并新增 `raw_station_grid()`（未投影，作为诚实审计口）与 `project_half_breadth()/half_breadth_mask()`；
   `volume` / `hydrostatics` / `vertices` / `quality` 全部走 `station_grid`，因此约束**对所有 v 构造性成立**。
   `vertex_jacobian` 携带同一 0/1 mask（被钉住的顶点 `∂y/∂v=0`），梯度链在新分支上仍精确。
   `quality()` 新增 `half_breadth_raw_min_m` / `half_breadth_clamped_vertices` / `half_breadth_clamped_fraction` / `half_breadth_significant_vertices`——修复量与原误差**同时上报**，不能互相掩饰。`SPACE_SCHEMA` → `/2`。
4. **工具链**：`tools/dtmb5415_param/run_acceptance.py` 新增 `--out`、每配置 raw/feasible 半宽列、对称面修复图；重跑三条判据 + `verify_geometry.py` + `verify_shipped_model.py`。
   复现（合计 <60 s，单核，本机 load15≈100 时按容量纪律只起单进程）：
   `PYTHONPATH=. python3 tools/dtmb5415_param/run_acceptance.py --out artifacts/m20271_5415_feasible`（24.5 s）
   `verify_geometry.py`（8.7 s）· `verify_shipped_model.py --n-configs 400`（13.7 s）
   `pytest tests/test_dtmb5415_param.py tests/test_golden_regression.py tests/test_iges_gold_regression.py -q`（71 passed, 91 s）

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **round 1 的失败量级被低估**：写的是「-1e-6 量级之外」，实测 raw 越界达 **-0.30 m**。审查口径应为「等于模型在该区域误差量级（RMS 0.25 m）」，不是数值毛刺。
2. **先排除再动手**：中线行 y 位移在真值里是 5e-12、在 PCA 基里自动为 0，所以「把中线行的 y 分量置零」这类直觉修法完全无效（实测删掉 0 能量）。真正的越界在 **中线邻域 girth 行**，且 knot 级 clamp 不够（细化后仍有 -0.104 m），必须在细化后的网格层收口。
3. **诚实警告：均匀抽样门从 8/20 变成 20/20，是因为门本身只卡对称面这一项**，不是因为模型在 `[-1,1]^27` 立方体内变好了。数据集流形之外的精度依旧不可用（留出集 RMS 0.25 m 是流形邻域的数），不得引用该 20/20 当精度证据。
4. **投影是分段仿射的**：切线在开关集上跳变（开关集 = 线性泛函的零水平集，测度零）。`vertex_jacobian` 在 mask 稳定时精确（实测 h=1e-5 最大偏差 1.5e-08 m；测试断言 stencil 两端 mask 相同）；`volume_gradient` 相对误差 3.07e-08。
5. **投影不改善精度**：壳体积变化 <0.03 %，排水体积 8417.45 → 8419.36 m³（真值网格 8439.38 m³）。它买的是**几何有效性**（可用于 CFD/BEM 蒙皮、无自穿），不是精度。
6. **真正的精度欠账仍在**：艉部近中线 `y` 尾巴的代理误差 ~0.25–0.5 m。修法方向=提高 rank / 加尾部形状特征 / 对流形外设计点做几何投影约束（未在本单预算内）。
